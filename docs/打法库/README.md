# 打法库说明

打法库是月度用户策略选择打法的依据。用户策略的推导链路是：时间节点 → 待办任务 → 核心痛点 → 决策障碍 → 心理机制 → 打法。工作台「策略 / 打法库」是主本；飞书阅读版由这里生成，不改动原手册。

- **原手册**：飞书《路觅教育线上课程促销打法手册》，本目录保存了一份只读副本：[源手册-路觅教育线上课程促销打法手册.md](源手册-路觅教育线上课程促销打法手册.md)。
- **词表**：心理机制（M01–M23）、决策障碍（A1–C1）、类别和阶段，统一定义在 `src/modules/user/playbook.js`。卡片只能使用词表中的标准名。

## 一、分类

共 11 类、47 种打法，外加 2 个呈现手段。分类原则是"这个打法回答用户的哪个问题"（2026-10-20 确认，取代原手册的 11 章）。

| 编号 | 类别 | 回答用户的问题 | 打法 |
|---|---|---|---|
| 01 | 价格让利类 | 现在多少钱 | 限时折扣、直降 / 立减、支付立减 |
| 02 | 时间窗口类 | 为什么现在买 | 早鸟价、阶梯降价、前 N 名加赠、涨价预告、封班 / 截止报名 |
| 03 | 量价组合类 | 多买是否更划算 | 满减（含满减券）、满额加赠门槛、连报优惠、多科联报、自选课包 |
| 04 | 产品与陈列类 | 该买哪个 | 班型梯度（含对比陈列）、加价升级、正课 + 服务打包、全程班 |
| 05 | 权益加赠类 | 多得到什么 | 赠题库 / 会员、赠 1v1 / 答疑、赠教辅 / 讲义、赠伴学 / 督学、加量不加价 |
| 06 | 体验与诊断类 | 值不值得信 | 低价引流课、免费试听 / 公开课、免费学业诊断 |
| 07 | 风险保障类 | 买错了怎么办 | 7 天无理由退、价保、学习保障条款 |
| 08 | 预售与支付类 | 怎么付 | 定金预售、预约 / 排队、分期免息、合规学费分期、储值 / 充值送 |
| 09 | 老客与会员类 | 老学员为什么继续 | 老学员续报价、学习会员、学员等级、积分体系、生日 / 节日关怀 |
| 10 | 定向触达类 | 优惠给谁、何时给 | 新客无门槛券、老客续报券、沉睡召回券、弃购挽回、渠道专属权益 |
| 11 | 互动激励类 | 怎么提高参与 | 签到 / 打卡、报名抽奖、红包雨、集卡 / 闯关 |

**与原手册相比的调整**：

| 调整 | 内容 |
|---|---|
| 合并 | 班次对比锚定并入班型梯度；满减券并入满减；定金膨胀与提前锁名 / 占位合为定金预售；直播 / 社群专属券与直播专属权益合为渠道专属权益；名额递减并入名额库存 |
| 改名 | 全程班 / 年卡改为全程班，学习会员 / 年卡改为学习会员，避免两处都叫"年卡" |
| 改为呈现手段 | 倒计时、名额库存，不再单独成卡 |
| 移除 | 跨品牌联合（属于获客导流，超出原手册边界） |
| 新增 | 免费学业诊断 |

## 二、卡片结构

每张卡片以一段「定位」开头，正文分七节，结构以 [P0201-早鸟价.md](P0201-早鸟价.md) 为准：

1. **心理机制**：写清原理与出处、作用路径、生效条件、失效条件
2. **用户决策路径**
3. **适用信号**
4. **不适用与反作用**
5. **方案设计**：分步骤，每一步对应一个心理机制，并说明步骤之间的先后依赖
6. **组合**：只补真实缺口
7. **文案示例**

**隐藏元信息**：写在卡片第二行，页面不展示，格式如下：

```
<!-- 编号 | 类别 N | 阶段 新签/续费/通用 | 障碍 主… ; 辅… | 机制 M.. M.. -->
```

- 障碍编号用于在页面上筛选，也供 T13 选打法时使用。
- 阶段对应月度策略 4.1 的新签、续费两栏。
- 机制列表的第一个是主机制。

**写作约定**：
- 拿不准的结论标注「推断」。
- 沿用原手册的规则标注「原手册」。
- 不写没有依据的折扣深度。

## 三、价格秩序

同一门课在同一招生周期内，各类到手价必须满足以下顺序：

> **老学员价 ≤ 早鸟价 ≤ 限时价 / 立减价 / 券后价 < 正价**

1. 老学员价最低。任何公开促销都不得低于老学员价；如果公开促销的力度更大，老学员自动按更低的价格执行。
2. 早报名的人不吃亏。早鸟截止之后的任何促销，都不得低于早鸟价；做不到时，用价保兜底。
3. 渠道专属价、支付立减叠加后的到手价，同样要遵守上面的顺序。
4. 设计任何价格类打法之前，先对照这张顺序表。违反顺序的方案不上线。

## 四、呈现手段

呈现手段本身不构成打法，必须挂在一个真实的截止日或真实的名额上，用来让用户"看见"这个限制。复盘时，不把它们算作独立的增长来源。

| 手段 | 挂在哪里 | 使用规则 |
|---|---|---|
| 倒计时 | 早鸟价、限时折扣、阶梯降价、封班等真实截止 | 只在最后 48–72 小时上线；到点即止，不永久挂"最后一天"（原手册） |
| 名额库存 | 小班制的真实班级容量，或前 N 名、早鸟限额等真实配额 | 展示"仅剩 X 席""已领 X / N"；数字必须真实（原手册）；班级席位和优惠配额分开展示；余量还很充足时不展示，否则反而显得不紧俏 |
