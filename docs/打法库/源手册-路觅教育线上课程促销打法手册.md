# 路觅教育线上课程促销打法手册

**适用范围：**本手册适用于路觅教育线上课程业务（大学辅导板块、国际课程板块）的促销活动设计，覆盖直播班课、录播课、1v1 辅导、训练营、会员/题库等线上交付形态。

**手册边界：**仅收录**纯线上、以促进新签/复购为直接目的**的促销打法；**不含**转介绍、老带新返佣、拼团砍价、分销裂变等依赖用户拉新传播的玩法，也不收录线下地推、讲座、展会等非线上动作。品牌广告、内容投放、SEO 等获客手段不在本册范围。

**选型速查：**拉新首单用"低价引流课 + 新客券"；提升客单价用"连报/多科联报 + 满减"；大促转化用"早鸟价 + 定金锁名 + 限时加赠"；促续报用"老学员价 + 续报礼包 + 学习会员"；犹豫客转化用"免费试听 + 7 天无理由退 + 价保"。

## 一、价格直降类

直接作用于课程标价，价格信号最清晰、转化链路最短，适合招生窗口期、大促节点和清尾班。课程为数字交付，无物流成本，直降的让利空间应优先让给"加赠权益"而非长期降价，避免价格锚点下移。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **限时折扣** | 报名窗口期内班课直降，如"全程班 8 折，限时 7 天"；以原价划线价做价格锚点 | 招生窗口冲量 | 折扣需对标真实近 30 天成交价，原价须真实可查，杜绝先涨后降 |
| **早鸟价** | 开课前 N 周/首批报名享 75–85 折，名额截止后恢复正价 | 提前锁名单、平滑招生节奏 | 早鸟名额和截止时间必须真实，过期即恢复正价 |
| **直降/立减** | 固定金额立减，如"立减 800 元" | 中高客单单课转化 | 金额感知强，适合千元以上班课 |
| **低价引流课** | 0 元 / 1 元 / 9.9 元体验课、3–7 天训练营，近乎无决策成本 | 前端获客、导入正价课转化漏斗 | 核心钩子；必须做好体验课到正价课的转化 SOP 与留资承接 |
| **老学员续报价** | 已报名学员续报下一阶段享专属折扣 | 提升 LTV、降低获客成本 | 与公开价拉开差距，体现老客身份 |
| **班次对比锚定** | 入门班 / 进阶班 / 全程班三档并列，用高配班衬托主推班性价比 | 引导选中高毛利主推班型 | 是定价陈列策略而非真降价，权益差异要真实 |

## 二、门槛与连报类

课程客单价高、决策重，"再报一科/再报一期就更便宜"是最有效的提客单（AOV）和提续报手段。门槛设计要让学员"够得着又愿意凑"。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **满减** | 多科/多单累计满 X 元减 Y 元，如满 3000 减 300 | 提客单价 | 门槛设在平均客单 1.2–1.5 倍 |
| **连报优惠** | 连报两期/两学期享减免，如连报两学期减 15% | 锁定长期学习、提 LTV | 注意预收费监管上限（见合规章），连报周期不超限 |
| **多科联报** | 同时报多科享联报价，如"语言+学术写作联报 8 折" | 提客单、横向扩科 | 科目组合要符合真实学习路径 |
| **阶梯降价** | 体验课结课当日报名立减 800，第 2–3 天减 500，3 天后恢复正价 | 趁热打铁促即时决策 | 截止时间真实，配套权益同步收回 |
| **满额加赠门槛** | 报名满 X 元/报全程班即赠教辅大礼包、纸质讲义包邮 | 提客单且不直接伤价盘 | 赠品成本低于等额打折 |

## 三、加赠与权益类

课程是"无形产品"，加赠的不是实物而是**学习权益和服务**。这类打法不破坏标价体系，还能强化课程价值感知，是教育促销的主战场。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **赠题库/会员** | 报班赠题库 VIP、模考系统会员、资料下载权限 | 强化课程价值感 | 边际成本低、学员感知高 |
| **赠 1v1 课时/答疑** | 报名即赠 N 节 1v1 规划课、作文批改、课后答疑权益 | 差异化、提升成交 | 高感知服务成本计入班型定价 |
| **赠教辅/讲义** | 赠纸质讲义、真题集、笔记本，包邮到家 | 提价值感、仪式感 | 成本可控，注意物流时效 |
| **赠伴学/督学服务** | 报名赠班主任督学、学习计划、打卡群服务 | 提完课率与口碑 | 服务要可交付，别过度承诺 |
| **加价升级（Upsell）** | 选基础班提示"加 X 元升级全程班/1v1" | 提客单、推高毛利班型 | 差价小、升级价值一眼可见 |
| **前 N 名加赠** | 前 100 名报名赠定制周边/名师签名资料/专属班会 | 抢跑转化 | 名额真实可查，赠完即止 |

## 四、课包与班型组合类

用"打包更划算"引导学员选更高客单的班型或更长周期的学习方案，同时提升完课和续费。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **班型梯度** | 同步班/强化班/全程班，权益逐级增加，价格递增 | 引导选中高客单班型 | 权益差异可量化（课时数、1v1 次数） |
| **正课+服务打包** | 正课 + 模考 + 批改 + 督学打包成"通关班" | 提客单、提交付完整度 | 打包价低于单买各项之和 |
| **全程班/年卡** | 覆盖整个备考/留学申请周期的全程班或年卡会员 | 锁长期、提 LTV | 受预收费周期监管约束，注意合规 |
| **加量不加价** | 同价增加课时/赠一阶段录播课 | 老客忠诚、护价盘 | 不降价只加量，避免价格锚点下移 |
| **自选课包** | "任选 3 门专题课享打包价" | 清长尾课、提件单 | 选品池控制毛利 |

## 五、优惠券类

优惠券的核心是**分层与定向**：把优惠给对的人（新客、犹豫客、沉睡老客），而不是所有人，以此保护公开价盘。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **新客无门槛券** | 注册/留资即发无门槛抵扣券或体验课兑换券 | 新客破冰、留资沉淀私域 | 面额适中，一人一券防羊毛 |
| **满减券** | 满 X 减 Y，需领取后使用 | 提客单、制造"已领未用"心理 | 与满减、折扣叠加规则提前算清 |
| **老客续报券** | 结课时定向发下一阶段课程券 | 促续报、提 LTV | 结课即发，趁学习惯性转化 |
| **沉睡召回券** | 对加购未报名、试听未买正价、30/60 天未活跃用户发大额券 | 召回流失意向用户 | 面额大于常规券才够动力回流 |
| **弃购挽回** | 购物车/订单未支付 N 小时后发券或提醒 | 挽回临门流失 | 时机精准，避免过度骚扰 |
| **直播/社群专属券** | 直播间、学员社群专属券码，公域不公开 | 私域转化、制造专属感 | 限渠道使用，保护公开价 |

## 六、预售与锁名单类

班课有名额上限，提前锁定名单既能平滑招生节奏，也能制造"名额递减"的紧迫感。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **定金膨胀** | 付小额定金抵大额学费，如 100 抵 1000 | 提前锁名单 | 明确未付尾款定金规则，书面公示 |
| **提前锁名/占位** | 付小额定金锁座位，开课前补尾款 | 蓄水、平滑招生 | 与早鸟价叠加规则清晰 |
| **名额递减** | 小班限 N 人，页面实时显示"仅剩 X 席" | 制造稀缺、促决策 | 名额真实，小班制须真能交付 |
| **预约/排队** | 爆款班满员后开放下一期预约排队 | 持续蓄水 | 排队顺位公开透明 |

## 七、游戏化与互动类

用于提升活跃、完课和复购触达，不依赖用户拉新传播。**注意：打卡返现/0 元学属监管高风险玩法，慎用。**

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **签到/打卡学习** | 连续签到领积分、资料、课时；打卡完成学习计划 | 提完课率、留存 | 奖励为积分/权益，不做"全额返学费" |
| **报名抽奖** | 报名即抽奖，奖品为课时、周边、续费券、免单名额 | 提转化、促活动氛围 | 中奖率和梯度合理，有大奖撑场面 |
| **红包雨/整点红包** | 大促直播间整点红包雨，红包为学费抵扣券 | 拉时段在线 | 红包导向当次/下次报名 |
| **集卡/闯关** | 浏览课程、参与公开课集卡，集齐兑资料/优惠券 | 拉长活动参与路径 | **合规提示：**不设"邀请好友助力"环节，避免落入裂变监管 |

## 八、会员与续报类

把单次报名变成长期学习关系，用等级、积分、权益提升复购与 LTV。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **学习会员/年卡** | 月度/年度会员，解锁录播库、题库、专属折扣 | 锁长期学习、提 LTV | **合规：**不诱导一次性缴超监管周期 |
| **学员等级** | 按累计消费/完课分等级，高等级享专属价与权益 | 激励升级、提复购 | 升级台阶清晰可感知 |
| **积分体系** | 报名、完课、签到得积分，抵现或兑资料/课时 | 增转换成本、促活跃 | 积分易获得、有去处 |
| **储值/充值送** | 充值学费账户送余额或课时 | 提前回笼、锁复购 | **合规：**不得诱导大额充值，受预收费监管约束 |
| **生日/节日关怀礼** | 生日月赠大额券、专属资料包 | 情感维护、促复购 | 可按大客户/普通学员分层 |

## 九、支付与金融工具类

课程客单价高，降低支付瞬间的决策压力是临门一脚的关键。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **分期免息** | 大额班课 3/6/12 期免息，或商家承担部分贴息 | 降低高价课决策门槛 | 明确贴息比例，算入获客成本 |
| **支付立减** | 指定支付方式/银行卡立减 | 促转化 | 多由支付方/银行补贴 |
| **合规学费分期** | 正规持牌机构的教育分期产品 | 降低一次性支付压力 | **合规：**不得诱导学生办理培训贷，须明示费用与风险 |

## 十、稀缺与紧迫营造类

叠加在上述打法上的"心理扳机"，用真实的时间和名额限制放大行动理由。课程小班制天然适合名额稀缺。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **倒计时** | 活动页挂"距早鸟截止 HH:MM:SS" | 压缩决策时间 | 时间真实，不永久挂"最后一天" |
| **名额库存** | "仅剩 X 席"进度条 | 制造稀缺 | 真实库存，不造假 |
| **涨价预告** | "X 月 X 日起价格上调至正价" | 促提前报名 | 涨价真实兑现，不反复食言 |
| **封班/截止报名** | 开课前 N 天封班，不再接受插班 | 保障教学交付 | 与排课、师资容量一致 |

## 十一、教育专项与信任保障类

教育是高客单、长决策、重信任的品类，"打消顾虑"本身就是最有效的促销。

| 打法 | 玩法与示例 | 核心目标 | 设计要点 |
|---|---|---|---|
| **免费试听/公开课** | 免费试听正式课片段、参加名师公开课/直播体验 | 建立信任、导入转化漏斗 | 试听质量即转化力，承接留资 |
| **7 天无理由退** | 报名后试听 X 天内不满意可全额退款 | 打消决策顾虑 | 规则清晰、退款顺畅，是承诺型保障 |
| **价保** | 报名后 X 天内降价补差价 | 消除"再等等"心理 | 明确价保窗口和补差规则 |
| **学习保障条款** | 未达约定学习进度可按规则重学/补课一期 | 降风险、提转化 | **合规：**表述为服务保障，不得用"保过/保分/100% 通过" |
| **直播专属权益** | 直播间专属价、专属加赠、限时名额、抽奖免单 | 直播转化峰值 | 权益限直播间，制造在场感 |
| **跨品牌联合** | 与留学/申请/文具等客群互补品牌互赠权益（不要求拉人） | 互相导流、低成本获客 | 选非直接竞争、客群一致的品牌 |

## 十三、选型与设计原则

真实大促按目标组合打法，常见组合如下：

| 核心目标 | 主打打法 | 配套与信任背书 |
|---|---|---|
| **拉新/首单** | 低价引流课、新客券、免费试听、公开课 | 7 天无理由退、留资进私域 |
| **提客单价** | 连报/多科联报、满减、加价升级、课包 | 满额加赠教辅/1v1 课时 |
| **招生窗口转化** | 早鸟价、定金锁名、名额递减、阶梯降价 | 倒计时、涨价预告、价保 |
| **促续报/LTV** | 老学员价、续报券、学习会员、积分、储值 | 结课即触达、生日礼 |
| **大促 GMV** | 定金膨胀 + 早鸟 + 直播专属 + 分期免息 | 红包雨、前 N 名加赠、名额制 |

**设计底线：**

- **算清毛利再叠加：**折扣、券、赠品、贴息叠加后，到手价必须覆盖师资交付与服务成本，避免"招一个亏一个"。
- **保护价格锚点：**能用加赠权益、定向老客券解决的，不长期全场直降；避免学员形成"不打折不报名"心智。
- **阈值科学：**满减/满赠门槛设在平均客单 1.2–1.5 倍；早鸟折扣控制在 75–85 折，过低会拉低品牌价值感知。
- **真实不造假：**名额、倒计时、原价、中奖率必须真实可兑现，稀缺是建立长期信任的资产。
- **合规前置：**所有促销物料按第十二章红线过审后再上线。
