# 用户策略规范

2026-10-19 与用户逐轮确认后定稿。工作台「策略 → 用户策略」页、飞书月度文档《用户策略 · YYYY-MM》、AI 生成与验收都以本文为准。

## 1. 定义与边界

**用户策略**：针对某个月，判断目标用户所处的时间节点和状态，拆出他们要完成的任务、卡在哪里、为什么还没购买，从中收敛出机会点，最终给出促销建议并说明背后的逻辑。

- **对象**：海外大学生（本科为主，硕士只标与本科明显不同的关键节点）。只覆盖大学辅导，不含申诉服务；国际课程的时间线不同，以后单独做。
- **重心**：用户情况梳理（第 1、2 段）是主体；促销建议是最终收敛呈现的一部分。
- **产出止于促销建议**：给出打法组合和理由，不定具体价格（定价归价格模块），不写触达话术，也不做上月复盘。
- **使用方式**：用户情况按月内置，任何时候切换月份即可查看、修改；促销策略在需要时按按钮生成，不绑定交付日期。

## 2. 推导链路

```
时间节点 → 待办任务 → 核心痛点 → 决策障碍 → 心理机制 → 打法
（情境）    （任务）    学业阻力      购买阻力      为什么有效
```

**痛点和障碍必须分开**：痛点是完成学业任务的阻力（例：写不好 Essay）；决策障碍是选择我们的阻力（例：觉得还来得及）。打法针对的是障碍，不是痛点。

## 3. 整体结构（结论摘要 + 4 段 + 附录）

| 段 | 名称 | 内容 | 回答的问题 |
|---|---|---|---|
| 0 | 核心结论 | 一句话月度判断 · 本月目标 · 核心打法 | 一屏读完的结论 |
| 1 | 全局研判 | 1.1 时间全景（地区 × 节点）· 1.2 跨地区共性与差异 · 1.3 地区分档 | 形势如何 |
| 2 | 用户洞察 | 分地区 6 格；硕士关注作为地区内附注 | 用户怎样 |
| 3 | 机会收敛 | 跨地区机会点合并、排序 → 本月目标 | 打哪里 |
| 4 | 促销策略 | 4.1 打法组合（新签 / 续费）· 4.2 选择逻辑 · 4.3 不选什么 · 4.4 底线 | 怎么打 |
| 附 | 依据与待确认 | 推测项、AI 判断项、打法库缺口 | 哪些还没证实 |

每一段只使用上一段的结论，不回头补充信息。

## 4. 地区单元：6 格

| 格 | 写什么 | 不写什么 |
|---|---|---|
| 用户节点 | 学期第几周、关键事件及日期、代表学校；外部节点（当地消费节点、中国节点） | 与本月无关的远期节点 |
| 待办任务 | 学生这个月必须完成的学业任务（JTBD） | 我们的产品 |
| 核心痛点 | 完成任务时的学业阻力 | 购买阻力（归入决策障碍） |
| 需求温度 | 冷 / 温 / 热，可写变化（温 → 热）以及转折日期 | 情绪描写 |
| 决策障碍 | 从第 6 节词表选 1–3 项，每项附一句具体描述 | 词表以外的自创说法（需要时先补充词表） |
| 机会点 | 业务线 · 产品方向 · 切入窗口（日期） | 具体价格 |

- 地区顺序（即权重）：英国 ≥ 美国 > 香港 > 澳洲 > 加拿大 > 新加坡 > 其他。
- 其他 = 新西兰、澳门、欧洲（目前只有爱尔兰）、马来西亚，合并写成一列。
- 工作台写满全部地区；飞书版在工作台内容的基础上补充依据和展开说明。
- **时间窗口**：目标月整月，加上下个月前 14 天（标为「提前预热」，不与当月节点混写）。

## 5. 地区分档

分档 = 固定权重 × 本月节点密度。

- **主战场**：权重高且本月有节点；或权重中等但节点密集（例：澳洲 11 月同时有 Final、出分、补考）。
- **次要**：有节点，但权重或密度一般。
- **平稳**：本月基本没有节点。

分档只用于标注和排序，不决定篇幅。

## 6. 决策障碍词表（Fogg 行为模型：动机 × 能力 × 触发）

| 类 | 编号 | 障碍 | 打法方向 |
|---|---|---|---|
| A 动机不足 | A1 | 没意识到需要 | 诊断、公开课 |
| | A2 | 觉得还来得及 | 时间杠杆：阶梯价、涨价预告、倒计时 |
| | A3 | 不信任效果 | 风险逆转：试听、无理由退、价保 |
| | A4 | 有替代品（学校资源、同学、AI 工具） | 差异化权益：1v1、批改 |
| B 能力受限 | B1 | 嫌贵 | 加赠、满额赠、分期 |
| | B2 | 怕选错 | 班型对比、诊断推荐 |
| | B3 | 没时间 | 短周期冲刺、按考点打包 |
| | B4 | 需要家长同意 | 面向家长的确定性表达 |
| C 触发缺失 | C1 | 没被触达 / 不知道我们能帮 | 定向触达、社群专属 |

词表可以增补，增补时同步更新打法库的索引。

## 7. 促销策略（第 4 段）

- **4.1 打法组合**：分新签、续费两栏，各列主打法和辅助打法，写明适用地区和时间窗。不分地区出方案。
- **4.2 选择逻辑**：每个打法写一行「决策障碍 → 心理机制 → 打法 → 作用路径」。心理机制用打法库里的标准名称。
- **4.3 不选什么**：2–3 条，写明本月不用哪个打法、为什么。
- **4.4 底线**：毛利、价格锚点、合规，各一句。
- **匹配规则**（2026-10-20 确认，取代模型生成）：
  1. 障碍权重 = 各地区决策障碍按分档累加（主战场 3 / 次要 2 / 平稳 1）；同分时先比涉及的主战场地区数，再按词表顺序。
  2. 新签栏用新签 + 通用卡，续费栏用续费 + 通用卡；续费栏不处理「不信任效果」「没被触达」。
  3. 从权重最高的障碍起，按打法优先表（`src/modules/user/playbook.js` 的 `PRIORITY`）选第一张可用的卡；第一张为主打法，其余为辅助；每栏最多 4 张，已被选中卡主治的障碍不再单独选。
  4. 卡片「不宜组合」里点名的打法不进同一栏；同一栏只用一种直接降价（限时折扣、直降 / 立减、支付立减、早鸟价、阶梯降价）。被挡住或障碍已覆盖的首选卡写进 4.3。
  5. 4.1 做法引用权重最高地区对该障碍的具体描述；4.2 作用路径用心理机制词表的标准释义；4.4 为固定三条（毛利、价格锚点、合规）。
- 打法只能从打法库（`docs/打法库/P*.md`，工作台「策略 / 打法库」）里选，存打法编号，页面显示卡片名称并链接到卡片；心理机制存 M 编号（`src/modules/user/playbook.js`）。正文里不写编号。

## 8. 来源标注

每条内容都标出来源，以便区分哪些有证据、哪些是推断：

| 标注 | 含义 |
|---|---|
| 时间线 | 来自飞书《2026 海外大学时间线》，可追溯到单元格 |
| 规则推导 | 由「事件 → 需求」对照表推导（例：Final 提前 14 天进入需求期） |
| 原声 | 来自留学之声（Voice）的学生原话（Voice 接通后启用） |
| AI 判断 | AI 依据常识推断，待你确认 |
| 推测 | 日期或事实本身未经确认（时间线里标为 guess 的，以及 AI 补充的硕士节点） |
| 你写的 | 你手动修改或补充的内容 |

## 9. 写作规范（AI 生成与验收的硬性标准）

对标一线互联网公司的策略文档：语言精炼、专业，结构清晰，逻辑严谨。

1. **结论先行**：每一段的第一句就是判断，不铺垫。
2. **主张 + 依据**：每条都要有依据；没有依据的标「AI 判断」。
3. **具体化**：有日期写日期，有学校写学校，有数字写数字；不写「大部分、较多、一定程度」。
4. **一条一个意思**：单条不超过 40 字，以动词或判断开头；一格内容多时拆成多条。
5. **术语统一**：障碍编号、打法名、心理机制名一律使用词表和打法库中的写法。
6. **禁用空话**：赋能、抓手、闭环、全方位、深度、打造、助力、持续发力等。

## 10. 飞书版比工作台多写的内容

每月一篇《用户策略 · YYYY-MM》，放在飞书知识库「策略 / 用户策略」目录下。在工作台全部内容的基础上，增加：

1. **事实依据**：每个节点列出学校、日期和时间线来源；推测项单独列出。
2. **时间全景图**：地区 × 节点的甘特图。
3. **心理机制展开**：每个选中的打法写清原理、作用路径和反例。
4. **打法对比**：候选打法 × 本月障碍的匹配表，说明为什么选这个、不选那个。
5. **待确认清单**：汇总全部「推测」和「AI 判断」条目。

## 11. 内容来源与状态

- **用户情况默认存在**：核心判断、1 全局研判、2 用户洞察、3 机会收敛按月预先写好，内置在 `docs/用户情况/YYYY-MM.json`（2026 全年由 Claude 按本规范与时间线逐月撰写，用户确认）。时间全景的节点条、各地区节点数、推测节点由 `scripts/user-insight-facts.mjs` 按时间线计算。工作台打开即可查看，逐格修改后保存在本地。
- **促销策略按按钮生成**：点「生成促销策略」，按第 7 节的匹配规则，由当月用户洞察与打法库内部匹配出本月目标、核心打法和第 4 段，不调用模型，即时给出；预览确认后保存。结构或编号不合规的结果不保存；字数、禁用词、正文编号、阶段错栏只提示。
- **逐格修改**：核心判断、本月目标（生成后）、1.2 三栏、1.3 分档、地区 6 格（含硕士关注）、机会收敛都可以改，一行一条，改过的行来源标「你写的」。4.1–4.4 只能重新生成。
- 促销策略状态分「草稿 / 定稿」。定稿后用户情况和本月目标仍可修改；重新生成促销需要确认覆盖。不保留历史版本。
- 接口见 `docs/API.md`「策略 · 月度用户策略（T13）」。
