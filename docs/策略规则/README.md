## 版本规则

- 每份文件有自己的版本号，写在上表和文件开头。月度策略的每个 revision 都记录它用到的各规则版本（见 Schema v2 的 `inputs.rules`）。
- 只改措辞、不改判定结果的，不升版本；改了枚举、阈值、窗口天数、映射或不变量的，升版本，并在文件末尾的「变更记录」写明原因。
- 规则级修改走方法论修订流程（[08-质量标准](08-质量标准.md) 第 4 节）：反馈 → 问题分类 → 修订候选 → 基准案例复验 → 常浩批准。AI 不在单月里自行改规则。
