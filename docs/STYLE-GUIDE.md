# 视觉规范

方向：浅色、简洁、信息密度优先；表格参考飞书多维表格，降低上手成本。所有值在 `src/styles.css` 的 `:root` 变量里。

## 颜色

| 变量 | 用途 |
|---|---|
| `--bg` | 页面底色 |
| `--panel` / `--panel-soft` | 卡片、表格底色 / 表头、次级底色 |
| `--text` / `--text-2` / `--muted` | 正文 / 次要文字 / 辅助说明 |
| `--line` | 所有边框与分隔线 |
| `--accent` / `--accent-soft` | 主操作、选中态 / 选中底色、蓝色标签 |
| `--green(-soft)` | 已完成、已录入 |
| `--orange(-soft)` | 待处理、未录入、示例标记、警告 |
| `--red` | 错误 |
| `--changed` | 与上月不同的单元格底色（只用于对比高亮） |

不新增颜色；确需新增先加变量。

## 字号与间距

- 正文 14px；辅助 12px（`.small`）；页面标题 20px；卡片标题 14px 加粗。
- 卡片内边距 14–16px；模块间距 `--gap`（16px）；分组之间 24px（`.stack`）。
- 圆角：卡片 `--radius`（8px），按钮、输入框 6px，标签 4px。

## 组件（`src/ui/components.jsx`）

| 组件 | 用途 |
|---|---|
| `PageHeader` | 每页顶部：标题、副标题、右侧操作按钮 |
| `Tabs` | 模块内子页切换（链接式，改地址栏） |
| `Segmented` | 同一页内的视图切换（不改地址栏） |
| `FilterBar` + `Select` | 筛选栏；`Select` 第一项固定「全部」 |
| `Card` | 内容块；标题可带图标，右上 `extra` 放链接或标记 |
| `Tag` | 状态：neutral 默认 / blue 有数据 / green 已完成 / orange 待处理 |
| `Button` / `PendingButton` | 操作；主操作 `variant="primary"`，每个区域最多一个 |
| `SampleBadge` | 示例数据标记，接口实现后自然消失 |
| `Loadable` | 统一加载中 / 出错显示 |
| `Empty` | 空状态 |

## 模式

- **左列表 + 右内容**：`.chat-layout`（助手、日报周报）。
- **卡片墙**：`.grid-3`（方案按 3 条业务线）。
- **图片网格**：`.material-grid`（物料）。
- **左右分栏编辑**：`.split`（方案录入：左原文、右预览）。
- 图标统一用 `lucide-react`，16px，`strokeWidth` 1.8。
- 窄于 900px：侧栏收为图标，多栏变单栏。

## 文案

- 按钮用动词短语：「确认入库」「新建物料」「导入 Codex 会话」。
- 不写「成功」除非已回读验证；写入类操作结果写明写了什么（如「已写入 6 行，更新 1 行」）。
