# 视觉规范 v2.4：位图风（Bitmap UI）

2026-10-15 起生效，取代 v1；2026-10-16 补充 v2.1（工作台 v3 全量改版，依据 `docs/design/diagnosis/`）；同日补充 v2.2（用户逐页验收后放开语义色，见第 1 节）；同日补充 v2.3（二次评审 P2：字号刻度见第 2 节，间距刻度落到组件层见第 6 节③）；同日补充 v2.4（第三轮：⌘K 命令面板、底部状态栏、对象档案页，见第 5、6 节）。**只做电脑端（≥1280px），不做手机端。**来源：用户收藏的「6 种像素风高级交互」（Dashboard EP.04）中的「位图风底座」与 6 种交互，按工作台的真实功能做了对应。参考样板：首页 `src/modules/home/HomePage.jsx`。

**一句话**：现代开发者工具里的位图风，克制，不做游戏化。页面结构由工作台的功能决定，不照搬参考图的排布。

## 1. 风格底座

| 项目 | 规则 | 变量 |
|---|---|---|
| 底色 | 冷灰白，叠 24px 点阵网格（2px 圆点） | `--bg #EDEEF1`、`--grid-dot #C9CCD3` |
| 面板 | 实底，2px 细线描边，**直角；不要阴影、圆角、毛玻璃** | `--panel #FBFBFC`、`--line #D5D8DE`、`--border 2px` |
| 墨色 / 次要灰 | 正文与主操作用墨色；次要灰在 v2.2 加深，保证说明文字可读 | `--text #0D0E10`、`--muted #686D76` |
| 品牌强调色 | 信号橙：当前项、新信号、主操作悬停，全页面积不超过 5% | `--signal #FF4F1F` |
| 语义色（v2.2） | **只用于需要读出含义的地方**：达成 / 风险 / 信息 / 待处理。每种配一个浅底，文字用深色、底用浅色；不做装饰，不大面积铺色 | `--ok #1E8E4E` 达成、`--risk #D92D20` 落后与报错、`--info #2563EB` 进行中与链接类信息、`--warn #B26B00` 待你处理；浅底 `--*-soft` |
| 层级与占比 | 用 Bayer 抖动网点的疏密表达，**不用透明度和渐变**；**网点不压在文字下面**，只用于进度条、比例条、空状态、悬停反馈等无字区域 | `--dither-1…4`（灰）、`--dither-ink-1…4`（墨）、`--dither-signal-1/2`（橙，慎用） |
| 画布白描边（v2.1 唯一颜色例外） | 只用于设计参考画布的素材卡片，用户指定的「白色描边」效果 | `#FFFFFF`，不进全局变量 |

旧变量名保留为别名：`--green` → `--ok`，`--red` → `--risk`，`--orange` → 信号橙。标签色调：`green` 达成、`red` 风险、`blue` 信息、`amber` 待处理、`orange` 品牌强调、`ink` 当前选中、`frame` 分类名（墨框白底，v2.3）。除上表外不新增颜色。

**语义色用法**：进度和完成度按「是否跟上时间进度」着色（跟上为绿、落后 15 个百分点内为琥珀、更多为红）；状态标签（已完成 / 进行中 / 卡住）用绿 / 蓝 / 红；「等你审核」「待确认」「草稿」用琥珀；报错文字用红。颜色之外必须同时有文字（如「落后」「还有 1 天」），不只靠颜色传达。

**时间线事件类别色（v2.2）**：只在用户时间线里区分事件类别，图例必须写明——考试为墨色、选课 / 开学为蓝、论文作业为紫 `#7C3AED`、假期为灰、出分为绿。条形用浅底加 3px 左边色条，文字始终是墨色。

## 2. 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 正文 | Geist + 苹方（中文） | 默认，中文一律用正常黑体，保证可读 |
| 标签 | Geist Mono，11px，全大写，字距 0.08em | `.label`：卡片小标题、日期行、表头、状态 |
| 数字 | **Geist Pixel**（像素字体） | `.num` / `<FlipNumber>`：**每张卡最多 1 个主数字**（如交付天数、倒计时）。表格、价格、日期一律用 Geist Mono 等宽并右对齐（`.tnum`），避免 0/8、6/9 看错 |

**字号刻度（v2.3）**：主区只用下面 7 级。字重只用 400 和 600，StatStrip 数字的 700 是唯一例外；浏览器给标题、`b`、`strong` 的默认粗体已在 `styles.css` 统一压到 600。

| 层级 | 字号 / 字重 | 用在 |
|---|---|---|
| 页标题 | 22 / 600 | `.page-header h1`；首页问候 30 / 600 是例外 |
| 分组标题 | 18 / 600 | 页内分组（`.section-head`、方案汇总）、文档一二级标题、Voice 话题标题 |
| 卡标题 | 14 / 600 | 卡头、阶段名、战役名、文档三级标题 |
| 正文 | 13 / 400 | 全站默认字号（`:root`）；句中强调用 600 |
| 次要文字 | 12 / 400 | `.small`、说明、日期 |
| 标签 | 11，Geist Mono | `.label`、`.tag`、表头、角标 |
| 数字 | StatStrip 24 / 700；表格主数 16 / 600，Geist Mono | 像素主数字见上表「数字」 |

不受刻度约束的：像素数字（`FlipNumber`、倒计时、交付天数）、词云、缩略图示意（9–10px 只留在这里）、阶段条编号（Geist Mono 20，P1-10 定稿）。

字体文件在 `src/assets/fonts/`（OFL 许可），不依赖网络。

## 3. 像素只出现在这些地方

数字、7×7 像素图标（`<PixelIcon>`）、点阵图（`<DotMatrix>`）、抖动网点、1-bit 头像（`<BitAvatar>`）、方块光标（`<TypeText>`）。正文、按钮文字、表格内容不做像素化。

图标统一用 `PixelIcon`，稿子在 `src/ui/icons7.js`：**7×7 实心网格**（v2.2，用户 2026-10-16 在 `docs/design/icons-compare.html` 选定 C 方案），块面优先、少用单像素细线，粗细与像素数字一致。只按 14px（每格 2px）或 28px（每格 4px）渲染，不缩放到其他尺寸。缺图标就在 `ICONS7` 里按同一网格画一个；**不使用 lucide-react**。

## 4. 动效：一律按帧跳变

约 15 帧/秒（`FRAME = 66.7ms`）。**不用缓动、弹簧、模糊，也不用 CSS transition。** 系统开启「减少动态效果」时直接显示终态（组件已内置）。

| # | 交互 | 组件 / 机制 | 用在哪里 |
|---|---|---|---|
| ① | 点阵数字滚动：只滚变化的位，个位先停、高位后停，每位停住时闪一帧橙色 | `<FlipNumber value>` | 指标卡；刷新后会变化的计数（篇数、SKU 数、物料数） |
| ② | 点阵亮起：从左到右、自下而上逐点点亮，最新一批为橙色；当前列常亮橙色 | `<DotMatrix data highlight>` | 首页「促销变动」；以后的业务数据图 |
| ③ | 像素溶解转场：16px 方格，共 3 帧（约 200ms）：盖住一半 → 盖满并换页 → 揭开 | `App.jsx` 已接好 | **只在切换模块时**；模块内子页不溶解 |
| ④ | 抖动网点悬停：四档逐帧加密，移开逐档退回 | 给元素加 `data-dither`，或 `<Card dither>` | 可点击的卡片、列表项、物料卡 |
| ⑤ | 方块光标逐字打出：光标先闪两次，逐字输出，数字标橙，打完光标消失 | `<TypeText text streaming>` | **Agent 流式回复**；生成类摘要 |
| ⑥ | 按帧加载：20 格逐格点亮，百分比同步跳，完成后显示像素对勾 | `<StepProgress progress done error>` | 方案解析入库、图片上传、日/周报刷新、Agent 等待首字 |

组合原则：一个页面最多同时出现两种动效（例如点阵亮起 + 按帧加载），不要每处都动。

## 5. 组件规则

- **按钮**：2px 墨色描边；主按钮墨底白字，悬停变信号橙；普通按钮悬停反色。每个区域最多一个主按钮。
- **选中态**：反色（墨底白字）。侧栏选中项左侧贴边加 4px 信号橙竖条。
- **标签 `Tag`**：等宽小字、1px 描边。`green` 表示已完成（墨底），`blue` 表示有数据（墨框），`orange` 表示待处理或警告（橙框），`neutral` 为灰框。
- **页签**：选中页签为面板底，和下方内容连成一体。
- **分段切换**：2px 墨框，选中段反色。
- **下拉框**：2px 墨框，用像素下箭头，直角。
- **表格**：表头用等宽小字；数字列等宽右对齐。和上月不同的格子用**白底** + 左侧 3px 橙线 + 右上角「改」角标，不用网点底；旧值在格子里用删除线写出，或悬停显示。
- **警告 `.warn`**：面板底 + 左侧 4px 橙线，文字用墨色。
- **示例标记**：橙色虚线框。
- **空状态**：2px 虚线框。
- **示例数据**：接口未实现时页面显示示例数据，并标「示例」（橙色虚线框小字，悬停看接口清单编号）。
- **弹窗**：2px 墨框、直角；遮罩用 `--dither-ink-1` 网点铺满，不用半透明黑。
- **状态标签 `.state`**：已完成为墨底，进行中为墨框，待处理为灰框空心点，卡点为橙框。
- **悬浮效果**（只用于设计参考画布）：不用阴影。在卡片右下错位 6px 放一块 `--dither-ink-2` 网点；悬停时一帧跳到错位 9px、网点加深，同时加 2px 墨框。
- **隐藏**：全局 `[hidden] { display: none !important; }`。
- **命令面板（v2.4）**：⌘K / Ctrl+K 在任何页面打开，`src/modules/command/`。墨色网点遮罩 + 2px 墨框，宽 820，居中于主区；输入行 56px，下面一排范围按钮（全部 / 页面 / SKU / 学校 / 需求 / 文档 / 操作）。结果按组排（SKU → 操作 → 学校 → 需求 → 文档 → 页面），组名用等宽小字并写条数；选中行反色 + 左侧 4px 橙条，和侧栏选中一致；命中的字浅琥珀底，选中行里改成橙底白字。右侧 280px 预览选中项的关键数字，底部一行快捷键提示。键盘：↑↓ 选择、↵ 打开、Tab 切换范围、输入「>」只搜操作、Esc 关闭。没输入时显示「最近」5 项和全部页面。不加动效；接口未实现的组标「示例」。
- **底部状态栏（v2.4）**：26px 实底，上边 1px 细线，等宽 11px，`src/modules/statusbar/`。每组写「点 + 名称 + 值」：绿点正常，琥珀点有问题（悬停看原因），灰色空心点未接入。只写真实数据，不放示例；只读，不触发同步。Codex 不放这里（顶部横条已有）。右侧是 ⌘K 入口和本机地址。
- **对象档案页（v2.4，首个是 SKU 档案）**：一个对象一页，不显示页签。自上而下：返回链接 → 页头（像素图标 + 对象名，副标题写所属与用途）→ StatStrip → 跨月表（行是字段、列是月份；交付月一列表头墨底 + 橙色「交付月」角标、格子浅底；「改」沿用表格规则，悬停看旧值）→ 6/6 两卡等高。页面上真的显示了示例数据才标「示例」。

## 6. 版面（v2.2：统一对齐基准）

版式规则集中在 `src/styles-layout.css`，最后加载，只管位置、尺寸、间距，不管颜色。改版式先改这里。

- **外框**：顶部窗口条（`.chrome`）→ Codex 预警横条 → 左侧侧栏（「工作」「协作与工具」两组，设置在底部）。右侧自言自语抽屉宽 400px。底部状态栏 26px（`--statusbar-h`，v2.4）：侧栏、抽屉、撑满视口的页面（Agent、日报列表）和吸底的条（知识库暂存条、轻提示）都让出这一条。主区内边距 32px，**内容区全站同宽**，任何页面不单独限宽。
- **① 12 栏切分**：多栏布局只从 12 栏里取：`cols-6-6`、`cols-9-3`、`cols-3-9`、`cols-5-7`、`cols-4-4-4`。同一页上下两段尽量用同一种切分，或让分栏线落在上面数字条 / 阶段卡的格线上，竖向边线贯通。
- **② 并排等高**：同一行并排的板块底边必须齐平。短的一栏拉伸到同高，空白留在卡内底部；一栏叠多张卡时，最后一张吸收剩余高度。很长的文档旁边的列表，栏框等高、列表本身吸顶滚动（日报页）。
- **③ 间距刻度**：只用 4 / 8 / 12 / 16 / 24 / 32（`--s1`…`--s6`），组件层的 gap / margin / padding 也一律写变量。6px 只用于图标、色块和文字之间；1–3px 的微调、对齐用的结构值（如设置页 150 + 12 的缩进）不在此列。卡与卡 16；页头 → 页签 → 内容固定 16；首页问候下方 24；大分组之间 24–32 并加分隔线（如月度促销的「当月促销 / 方案汇总」）。
- **④ 卡头固定 48px**：标题 14px 600，图标与标题间距 6px；卡头里的按钮一律 28px 小号；卡体内边距 16px。
- **⑤ 控件高度**：工具栏里的按钮、分段切换、筛选标签、搜索框、下拉、月份切换、业务线切换一律 32px；卡内小控件 28px；表格内迷你按钮 24px。
- **⑥ 图标视觉对齐**：在按钮、卡头、标签里按中线对齐（`vertical-align: middle` 或弹性盒居中），与文字间距 6px；正文行内图标下沉 1px。
- **⑦ 概况数字条**：统一用 `StatStrip`（`.stat-strip` / `.stat`）：等宽格、左对齐，上面等宽小标签、中间 24px 粗体数字、下面一行说明。可点击的格（如知识库健康检查）整格是按钮，选中反色。格数尽量与下方分栏对应（项目推进 5 格对 5 个阶段卡）。
- **页头**：标题 22px（首页问候 30px）；页面级的示例标记和更新时间放在页头右侧。
- **页面说明（v2.3）**：Geist 12px、muted 色、不加粗；中文句子不用等宽字体，等宽只给日期和编号（首页日期行）。没有页签的页面写在标题下一行（`PageHeader` 的 `subtitle`）；有页签的模块写在页签下第一行（`Tabs` 每项的 `desc`），随页签切换，与下方内容隔 16。用户时间线的说明在视图里，右侧带数据来源。
- 只做电脑端（≥1280px）。

## 7. 文案

- 按钮用动词短语，如「确认入库」「新建物料」。
- 标签和英文小标题用全大写等宽，如 `WK 42`、`DONE`；中文标题不加修饰。
- 没有回读验证，就不写「成功」。写入结果要写明具体做了什么。
