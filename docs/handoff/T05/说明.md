# T05 日报周报交接

2026-10-14，Codex 实现完成，待 Claude 和用户验收。

## 使用

已安装的 Node 24 与 lark-cli 即可，无新增依赖。部署本次代码并重启工作台后，在「设置 → 日报文档链接」填写用户提供的链接，先预览再确认保存，随后进入「日/周报」。点击日期查看，点击「复制」复制正文，点击「刷新」重新读取飞书。日报、周报共用该链接。

内存缓存随进程退出失效；修改来源链接后自动重新读取。登录过期、缺少文档权限、网络/超时或不支持的文档链接会明确报错，不返回旧缓存冒充新内容。页面保留「设置来源」和「刷新」入口。缺登录时完成 codex 配置的 lark-cli 用户登录；无权限时核对同一用户和 codex 应用的文档访问权限，再刷新。

本轮没有替用户修改默认库或重启现有 5280 服务。只读核查时默认库没有 report_doc_url，用户在会话补充的链接只保存到了隔离库。正式实例的配置和运行采用尚未验证。
