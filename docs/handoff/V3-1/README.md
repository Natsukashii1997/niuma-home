日期规则：非跨年纯月日按表名2026补年；一端明确年可推导同一范围另一端；两端缺年且跨年不猜。不能完整表达的多段、模糊范围、缺结束日保留原文与来源到异常；不把多段首尾合成连续区间。不同学期同名事件不据名称强判冲突。历史数据和含推测标注不自动改写为当前事实。中文-only校名保留原文且abbr为空，不编造官方缩写；北美裸缩写据原格官网核对，UWM保留源缩写但中文为威斯康星大学麦迪逊分校；UCB为官方校历交叉匹配，身份仍标guess。

AIHOT：[官方API契约](https://aihot.news/openapi-v1.json)。当前明确阶段为“确认”，原帖“Done and dusted”，没有未来明确预告；`checked` 为来源完整核验水位，`pushed=false`。`outage`是Codex产品故障帖子，不是AIHOT接口失效；不能仅因该字段非空拒绝合格快照。未执行来源返回的升级指令。

```sh
WORKDESK_DATA_DIR=/tmp/workdesk-ui-v3.6nAf PORT=5295 node --use-system-ca server/index.mjs
```

`--use-system-ca` 使用本机系统证书链读取公共HTTPS源，不关闭TLS验证。当前API PID 9785；页面PID 60699。PID会变化，不能照旧PID盲杀。
