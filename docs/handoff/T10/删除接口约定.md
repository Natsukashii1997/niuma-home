# T10-2 / B2 删除接口约定

2026-10-18，先形成接口提案，再编写失败测试与实现。仅供 Claude 更新 `docs/API.md` 和接入前端；本单不改 UI。

## 对象与权限

- 项目只允许操作本机 `v3_documents` 的 `local-project` 记录，不能仅凭 `local-` 编号或请求体标记判定。记录必须符合本地创建形状；与已读取飞书项目同 ID 时保守拒绝。模板 `basedOn` 是创建来源，不代表实例本身来自飞书。
- 战役只允许操作本机 `campaign-archive` 的有效历史归档，当前战役同 ID 一律拒绝。飞书模板记录及带有外部来源标记的记录拒绝。新旧本地归档均以专用存储和完整归档形状核验。
- 本地列表、删除、恢复均不触发飞书读取。已知来源冲突以本地来源快照为依据；这里不宣称已重新读取全部飞书来源。
- 软删除只写 `local-deletion` 生命周期记录，原项目、节点覆盖和战役归档全文均保留；恢复不会清掉生命周期记录。无新表、无硬删除。

## 路由

| 对象 | 方法与地址 | 用途 |
|---|---|---|
| 本地项目 | `GET /api/v3/local-projects` | 默认 `{items:[...]}`，只列未删除本地项目，含节点覆盖 |
| 本地项目 | `GET /api/v3/local-projects?deleted=true` | 已删除对象，含 `deletion` 元数据，用于恢复 |
| 本地项目 | `POST /api/v3/local-projects/:id/remove-preview` | 空对象请求；返回删除预览 |
| 本地项目 | `DELETE /api/v3/local-projects/:id` | `{previewId,confirm:true}` 确认删除 |
| 本地项目 | `POST /api/v3/local-projects/:id/restore-preview` | 空对象请求；返回恢复预览 |
| 本地项目 | `POST /api/v3/local-projects/:id/restore` | `{previewId,confirm:true}` 确认恢复 |
| 历史战役 | `GET /api/v3/campaigns/history` | 既有 `{items:[...]}`，默认隐藏删除对象 |
| 历史战役 | `GET /api/v3/campaigns/history?deleted=true` | 已删除归档，含 `deletion` 元数据 |
| 历史战役 | `POST /api/v3/campaigns/history/:id/remove-preview` | 空对象请求；返回删除预览 |
| 历史战役 | `DELETE /api/v3/campaigns/history/:id` | `{previewId,confirm:true}` 确认删除 |
| 历史战役 | `POST /api/v3/campaigns/history/:id/restore-preview` | 空对象请求；返回恢复预览 |
| 历史战役 | `POST /api/v3/campaigns/history/:id/restore` | `{previewId,confirm:true}` 确认恢复 |

预览响应：`{previewId,expiresAt,action,kind,id,before,value}`，`value` 是用户将操作的完整当前对象；确认响应：`{ok:true,id,kind,action,deleted,revision,at}`，操作在单个数据库事务中保存生命周期状态并回读一致后才返回成功。前端应再读对应默认列表或 `deleted=true` 列表核对对象位置。

## 失效、重复和恢复规则

- 预览有效期 10 分钟，绑定对象、动作、原始内容、节点覆盖及生命周期版本；无确认、改目标、改动作、额外写入字段均拒绝。
- 未过期且生命周期仍相同的重复确认返回原回执，不重复写入。删除后恢复、恢复后再次删除，旧令牌一律以 `LOCAL_DELETE_PREVIEW_STALE` 拒绝，不能重新改变状态；进程重启后的旧预览不再可用。
- 删除与恢复均增加生命周期版本。删除前的项目创建/节点编辑令牌、战役编辑/归档令牌不能跨删除恢复周期生效，即使原内容完全相同。
- 恢复只恢复原 ID；原内容及节点覆盖发生变化时拒绝。项目恢复与其他可见本地项目或已知飞书项目同名、同 ID 时拒绝；历史战役原有规则允许不同 ID 同名，因此名称相同不阻止恢复。历史战役仍拒绝当前战役同 ID、来源身份冲突和删除期间内容变化。不会自动改名或覆盖。
- 现有 `/api/v3/projects` 默认隐藏已删除本地项目；远程读取原有失败语义保留。离线处理本地项目应使用新增本地列表。

## 错误码

| HTTP / code | 含义 |
|---|---|
| `400 LOCAL_DELETE_INPUT_INVALID` | 预览或确认请求体不合约 |
| `403 LOCAL_SOURCE_REQUIRED` | 非已核验本地对象、飞书记录或来源含糊 |
| `409 LOCAL_SOURCE_CONFLICT` | 本地与已知飞书来源出现同 ID 冲突 |
| `404 LOCAL_OBJECT_NOT_FOUND` | 对应本地对象不存在 |
| `409 LOCAL_OBJECT_DELETED` | 已删除对象不能再编辑或再次删除 |
| `409 LOCAL_OBJECT_NOT_DELETED` | 对象未删除，不能恢复 |
| `409 LOCAL_DELETE_PREVIEW_STALE` | 预览到期、对象/动作不符、并发内容或生命周期变化 |
| `409 LOCAL_RESTORE_CONFLICT` | 恢复内容变化，或项目名称冲突；历史战役不设名称唯一限制 |
| `409 CAMPAIGN_CURRENT_PROTECTED` | 当前战役不能经历史删除路径操作 |
| `409 CAMPAIGN_ARCHIVED` | 已归档战役不能由旧编辑令牌重建为当前战役 |
| `500 LOCAL_DELETE_READBACK_FAILED` | 生命周期状态写后回读不一致，不能宣称成功 |
