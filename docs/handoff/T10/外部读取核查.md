## 首次失败、提示与完整性边界

1. **项目首次 502 是验证器错误，不计产品缺陷。** 首次 HTTP 耗时 0.004 秒，返回“飞书读取失败，请检查 codex 用户登录、读取权限和网络”。`a2-cli.ndjson` 第 93 行明确记录 `blocked:true`、命令为 `base +field-list`；该只读命令未出站。根代理为验证 hook 补入 `+field-list` 和 `+record-get`，仅重启隔离 5299，再读成功。通用错误提示不能据此推断用户登录、权限或网络真的失败；本轮没有对业务错误文案作修改。
2. **知识库部分正文不支持有真实提示。** `limitations` 和对应 4 个文档的 `error` 分别为“bitable 正文暂不支持字数、摘要及相似度读取”与“file 正文暂不支持字数、摘要及相似度读取”，`chars=null`；未将未知字数伪装成 0。`scopeNote` 同时说明引用仅核对工作台已登记来源，未登记不表示没有引用。
3. **来源可读不等于来源内容正确。** 时间线返回 330 条供人工核对的异常；本轮验证读取链路与状态水位，不裁定这些业务异常、不修改源内容。
4. **未实际触发的失败路径仍未真人验证。** 本次未发生飞书真实权限拒绝、断网、限流、分页截断或读取期间版本变化；现有代码中的对应分支和自动化测试不能替代本轮真实失败演练。不能据成功读取声称这些提示均已实测准确。
5. **运行采用边界。** 本轮证明固定快照在同款 PATH、隔离数据下可以读取；不等于正式 5280 已采用本轮改动、长期稳定或用户最终验收。
