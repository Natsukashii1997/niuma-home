# T10 第 2 批 · B3 Voice 标签避让方案

日期：2026-10-18。交付给 Claude 实现前端；本项只提供计算方案和合成用例，未修改界面或业务代码。

采用**稳定排序 → 向下推开 → 超过底边时反向回压**。当前最多4个标签，三步扫描足以保证边界和间距，容易直接放进现有组件。仅计算标签位置，不移动折线、方点或真实热度；不声称全局最小位移。

## 当前实现与参数

依据 `src/modules/voice/VoicePage.jsx:174`、`:200–215`，以及 `src/styles-v3.css:724–731`：

| 对象 | 当前值／语义 |
|---|---|
| SVG | `viewBox="0 0 1000 220"`，宽度100%、高度自适应 |
| 绘图区 | `L=40,R=260,T=12,B=26`；x为40–740，y为12–194，高182 |
| 真实点位置 | `pointY = 12 + (1 - spark.at(-1)/100) × 182`；末点x=740，方点8×8 |
| 末端文字 | x=750，baseline=`pointY+4`；12px `--font-sans`；标题超过16字符截断，后接`heat` |
| 数量与顺序 | `v.hot.slice(0,4)`保持来源顺序；原数组第1项为粗线及强调色 |
| 交互 | 当前整图`role="img"`，末端文字没有点击行为 |

相同末值给出相同baseline，因而重叠。定位必须取最后一个`spark`值；`heat`仍按原逻辑展示，不替换数据、不假定两者必然相等。

全部计算使用 **SVG viewBox单位**，不与屏幕CSS像素混算。建议初始统一标签槽高`h=16`、槽间距`g=6`，中心距`D=h+g=22`。标签中心可用区间为：

```text
low  = T + h/2        // 默认20
high = H - B - h/2    // 默认186
baseline = labelY + 4
```

16是计算用的初始槽高，**不是本轮实测字体高度**。Claude接入时应等字体就绪，用文字`getBBox()`校核所有标签：设相对文字baseline的包围盒顶部为`a`、底部为`b`，统一半槽高取所有标签的`ceil(max(8, -(a+4), b+4))`最大值，`h=2×半槽高`。这样当前`+4`基线偏移也被包进槽内；字体、文字或图高变化后重新计算。保持单行，不能把12px字号直接当成字形高度。

## 计算规则与短伪码

1. 复制输入，仅按`pointY`升序排列；相同时按稳定唯一`id`的确定性字符串顺序排列。不要按标题或当前数组下标打破平局，不改变源数组。
2. 先把中心夹在`[low,high]`；从上到下令后一项至少比前项低`D`。
3. 若末项超过`high`，固定末项为`high`，再从下到上令前一项最多为后一项减`D`。
4. 结果按`id`映射回原来的`topics.map((t,k) => …)`。因此第一名样式仍按原来的`k===0`，只更换文字的y坐标。

```js
function labelLayout(topics, { H=220, T=12, B=26, h=16, g=6 } = {}) {
  const n = topics.length, band = H - T - B, D = h + g;
  if (!n) return { mode: "labels", labels: [] };
  if (n*h + (n-1)*g > band)
    return { mode: "legend", ids: topics.map(t => t.id) };
  const low = T + h/2, high = H - B - h/2;
  const a = topics.map(t => ({ id: t.id,
    pointY: T + (1 - t.spark.at(-1)/100)*band }));
  a.sort((p,q) => p.pointY-q.pointY || (p.id<q.id ? -1 : p.id>q.id ? 1 : 0));
  a.forEach((p,i) => { p.labelY = Math.min(high, Math.max(low,p.pointY));
    if (i) p.labelY = Math.max(p.labelY,a[i-1].labelY+D); });
  if (a[n-1].labelY > high) {
    a[n-1].labelY = high;
    for (let i=n-2; i>=0; i--)
      a[i].labelY = Math.min(a[i].labelY,a[i+1].labelY-D);
  }
  return { mode: "labels", labels: a };
}
```

输入沿用服务端已校验的唯一id、7天完整`spark`及0–100有限热度。计算只新增`pointY/labelY`，不要改写输入数组或任何`spark/heat`。同值重排的结果固定；真实值的上下次序改变时，标签顺序跟随真实点改变。

前扫已保证相邻中心距不小于D，回压继续保持该条件。提前验证`n×h+(n−1)×g ≤ band`，因此回压不会把第一项推过low。该策略优先保留较上方标签原位，必要时才推开冲突；底部不足时再回压，**不保证总位移最小或上下对称**。例如两个50分标签给出103、125，而非强行对称分开。

## 放不下、引线和点击

- 若`n×h+(n−1)×g > band`，返回`mode:"legend"`，不输出末端标签位置。Claude可保留真实图线，并在图下用原来源顺序显示完整图例；不能缩小字号、丢掉标签或输出重叠坐标。默认4项只需82单位，小于现有182；退化主要覆盖字体槽过大、图高变小或未来增加话题数。
- 文字保持x=750、baseline=`labelY+4`。只有`labelY≠pointY`才建议画细引线：从末点方块右边`(744,pointY)`连到文字左侧`(748,labelY)`；不将引线接入原趋势polyline，也不改数据点位置。沿用所属序列的强调／普通语义，引线`pointer-events:none`。相同末值的引线可以共起点，不能因此挪动真实末点。
- 保持当前无点击语义，不新增功能。若Claude后续要接“选中话题”，须按`id`映射到原话题，提供键盘与可访问名称；不能用避让后的排序下标选择对象。图例退化也保持相同id语义。
- 当前文字右侧可用250单位，字符截断不等于实测宽度足够。引线仅有4单位横向空间、标题字形及水平溢出都需Claude实际视觉核对；本轮不据几何结果宣布这些表现合格。
