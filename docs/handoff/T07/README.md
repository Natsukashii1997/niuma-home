## 使用顺序

无需安装新依赖，沿用项目已有 Node.js 24 与 npm 环境。

1. 点侧栏底部齿轮「设置」，或品牌页的「配置链接」。
2. 分别填写品牌多维表格链接、日报文档链接、物料类型清单。链接须使用 HTTPS 飞书域名；物料类型每行一个。
3. 点该项「预览保存」，核对最终值，再点「确认保存」。类型会去掉空行、首尾空白与重复项；修改输入会使已有预览失效。保存一项不影响其他两项草稿。
4. 页面回读核对后显示已保存值。返回品牌页可看到「在飞书打开」；重新打开物料录入窗口会使用保存的类型选项，原有物料的旧类型仍能显示。

出现保存失败或回读失败时，该表单停止写入，并标出上次读取的值。点「重新读取配置」核对实际保存结果，读取恢复后可继续编辑；不会自动重复提交。日报链接仅保存来源配置，本单不接入日报文档读取。
