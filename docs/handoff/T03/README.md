状态：2026-10-14，Codex 实现与隔离验证完成，待 Claude 和用户验收。

## 使用顺序

无需新增依赖，沿用项目已有 Node.js 24 与 npm 环境。在「营销 → 物料」操作：

1. 点「新建物料」，填写月份、业务线、名称、类型、可选 SKU 与备注；点「预览物料」，核对后「确认新建物料」。
2. 保存后即进入详情。拖入或选择多张图片，在本地预览后点「确认上传」。支持 PNG、JPG、JPEG、WEBP、GIF，单张不超过 20MB（20 × 1024 × 1024 字节）。
3. 点物料卡片查看详情，使用左右按钮浏览图片。「编辑物料」同样先预览后确认；删除图片或整个物料均需再次确认。
4. 选定类型，可加业务线筛选，再点「同类跨月对比」。每月一列，显示各物料的第一张图；此时忽略列表的月份筛选。

显示「已保存」「已上传」「已删除」前均执行回读。出现网络中断或回读失败时，写按钮会锁住：点「刷新页面核对」，查看实际已有物料和图片，再处理未完成项，不要整批重复上传。配置未提供有效类型数组时使用派单默认类型；SKU 仅来自同月同业务线的促销记录，允许不选。
