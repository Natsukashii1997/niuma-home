Codex 已完成派单七项实现与隔离验证，状态为「待验收」。文件清单与交接见 [CURRENT.md](../../../CURRENT.md)。

## 使用与复核

无需安装新依赖。在项目目录执行：

```sh
WORKDESK_DATA_DIR=$(mktemp -d) npm test
WORKDESK_DATA_DIR=$(mktemp -d) npm run build
WORKDESK_DATA_DIR=$(mktemp -d) PORT=5290 npm start
```

打开 [营销 → 促销表](http://127.0.0.1:5290/#/marketing/promos)。新隔离库为空时，先通过 T01 方案页面预览、确认两个月的方案；例如在 2026-08 和 2026-09 国际课程中分别录入正价 ¥7900版、¥8500版，再返回促销表对比。结束复核后在终端按 Ctrl+C。

- 点击分组行或其箭头可折叠/展开；行右侧提供「全部展开」「全部折叠」。三种分组都可用，键盘焦点下按空格也可操作。
- 悬停或用键盘聚焦高亮格，浮层显示上一个有数据月份的值，保留换行；可移入浮层阅读，按 Escape 关闭。
- 分组方式、月份、业务线和 SKU 筛选会在刷新后保留；浏览器禁用存储或记录损坏时，回到默认按月份、全部筛选，页面仍可操作。每次进入页面默认展开分组。
- SKU 选项随业务线更新，无效的旧 SKU 会清空，可用的同名 SKU 保留；两条业务线的同名 SKU 独立比较。
- 按 SKU 分组时记录按月份倒序，标题展示完整历史中的「最近变化」月份；筛选只改变显示记录，不改变比较基线。首次出现且没有历史变化的 SKU 显示「暂无变化记录」。
- 在表格区域内滚动，表头保持可见；窄屏可横向滚动查看其余字段。
- 方案保存并回读通过后，「确认入库」置灰。复制原文不会恢复按钮；重新解析后可确认。编辑原文会使旧预览失效，仍须先解析再确认。首次原文即使与促销表完全同值，也允许保存原文。
