## 使用

进入「Agent」，在对话顶部选择模型和强度。换模型会自动选择该模型的默认强度；显示“已保存并回读”后，从下一条消息起生效。下方“当前生效”来自 Codex 会话回读，保存后暂时仍显示上一轮值是正常行为。

选择“跟随默认”后强度框置灰，下一条消息会恢复 Codex 当前全局默认模型和强度。模型列表或保存失败时查看页面原因并点击重读；模型不可用时重新选择或恢复默认。发送过程中不可更改设置。

本轮按用户最新决定修正了“恢复默认”的语义，详见 `协议核查.md`；未改接口路径和数据形状。没有新增依赖或改动骨架。
