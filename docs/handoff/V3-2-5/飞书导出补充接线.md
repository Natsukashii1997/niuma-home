# 飞书导出补充接线 · 2026-10-16

此补充替代本目录旧说明中「brief export 固定 403、仅生成预览」的表述。受控写入代码已实现；本轮没有执行真实飞书创建，也没有修改 UI。

## Claude 接线

| 对象 | 预览 POST | 确认 POST |
|---|---|---|
| 设计 brief | `/api/v3/briefs/:month/export-preview` | `/api/v3/briefs/:month/export` |
| 已采纳需求策略 | `/api/v3/needs/:id/strategy/export-preview` | `/api/v3/needs/:id/strategy/export` |

brief 预览提交 `{ "targetUrl": "https://租户.feishu.cn/drive/folder/实际文件夹token" }`；策略预览额外提交 `month: "YYYY-MM"`。目标必须是准确的飞书文件夹链接，不能是旧文档或默认根目录。

预览返回 `previewId`、`expiresAt`、`mode: "new-only"`、`target: {title,url,token}`、新文档 `title`、完整 `markdown`、`sections`、内容 `fingerprint`。界面应展示真实文件夹名称、链接、新文档标题和全文，再让用户明确确认。策略只从 `needs.list(month)` 中读取当前有效的已采纳项；未采纳、待复核或来源已失效时拒绝导出。

确认仅提交 `{ "previewId": "预览ID", "confirm": true }`，10 分钟有效；不可附带替换内容、目录或月份。配置、内容、用户身份、目录名称发生变化时，先重新预览。

成功返回持久收据，主要字段为 `operationId`、`previewId`、`scope`、`status: "success"`、`target`、`title`、`document: {id,url}`、`fingerprint`、`sourceIdentity`、`startedAt`、`verifiedAt`、`readbackFingerprint`。同一导出重放返回原收据，不重复创建。

失败响应保留 `error`、`code`，结果未知时另带 `receipt`。`EXPORT_RESULT_UNKNOWN` 表示创建或回读未能确定，不等于创建失败；必须显示已知文档链接或目标文件夹并停止重试创建。更改标题、内容后重新预览也不能绕过同对象的未知收据。

状态和恢复入口：

| 对象 | GET 状态 | POST 只读核对 |
|---|---|---|
| brief | `/api/v3/briefs/:month/exports/:operationId` | 同路径加 `/reconcile` |
| 策略 | `/api/v3/needs/:id/strategy/exports/:operationId` | 同路径加 `/reconcile` |

两个入口均按对象限定收据。只读核对不接受替换目标或内容，也不再次调用 create；只针对收据已保存的文档 ID 和地址，重新读取全文及元数据并与原预览核对。匹配后落 `success`，再次确认返回原成功收据。状态响应和核对响应含 `sourceChanged`、`verificationNote`；收据 `source` 保留原配置，配置已切换也只核对原文档。

没有取得文档 ID 或地址时保持未知，明确引导人工检查原文件夹，不按标题猜测、不自动解锁，不删除收据后重试。已知地址但回读仍失败或内容不符时继续保留未知，可稍后再次执行只读核对。

## 实现边界

- 仅调用本机 `lark-cli --profile codex ... --as user`。`whoami` 不加 `--format`，单独核对根对象的 `profile`、`appId`、`identity`、用户、可用状态。
- 创建前用 `docs +create --dry-run` 核对应用、用户，以及计划 POST 中的完整内容和 `parent_token`。只接受一个新文档创建动作，不使用覆盖/更新接口。
- 正文走标准输入，用户原始文字转义为字面内容，不执行正文里的图片、文件、XML 或提及指令。
- 先用 `v3_documents` 保存 `feishu-export-preview`，实际写入前提交 `feishu-export` 的 `started` 收据。创建只调用一次；再读取整篇 Markdown 与文档元数据，逐项核对标题、ID、链接及全文顺序。成功或未知状态均持久保存。
- `started`、`unknown` 收据跨服务重启阻止再次创建；创建成功但回读失败也不会重放创建。
- 只导出七节 brief 或已采纳策略，不上传素材附件，不覆盖旧文档，不同步回需求或修改飞书表格。
