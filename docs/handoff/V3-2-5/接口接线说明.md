## 本地预览确认接口

确认请求为 `{previewId,confirm:true}`，带教记录另传预览时的`week`；预览十分钟有效、绑定旧值和内容；并发变更409，重复确认返回原回执。确认后回读。本轮不写飞书。

| 带教记录 | POST `/api/v3/mentor/:name/records/preview` | POST `/api/v3/mentor/:name/records`；GET `/api/v3/mentor`；POST `/api/v3/mentor/refresh` |
| 价格矩阵 | POST `/api/v3/price/schemes/preview?sku=` | PUT同路径去掉preview；活动方案必须关联真实已采纳needId；破底线必须填写breachReason |
| 战役 | POST `/api/v3/campaigns/current/preview` | PATCH `/api/v3/campaigns/current` |

## 人工AI草稿（不自动运行）

- 带教：POST `/api/v3/mentor/:name/draft/preview`传`{}`；使用已配置的近30天完整正文，生成后返回本地预览。POST `/api/v3/mentor/:name/draft`传`{previewId,confirm:true}`保存。来源、配置或正文变更后必须重新生成；返回内容始终标AI草稿，不回写日志。
- 自言自语：POST `/api/v3/selftalk/digest/preview`传`{week:"2026-W41"}`；POST `/api/v3/selftalk/digest`传`{week,previewId,confirm:true}`。必须是已结束、且最近10天完整覆盖的北京时间自然周；当前周五首次读取不能完整覆盖上一周，会409，不能扩读或补造。
- GET不触发模型。复用已有本机Codex登录和用户默认模型，不安装新模型、不使用Voice付费引擎；需要用户点击生成按钮。生成正文最多120000字输入，不静默截断；输出标草稿。调用质量本轮未真实验收，测试使用mock。
- 调度仅候选方案：每周一由人工触发上周汇总预览，确认后本地保存；若以后需要自动生成预览，另行授权定时任务，不自动确认或推送。

## 知识库整理确认与异常恢复

`POST /api/v3/kb/preview`传`{ops:[{type:"mkdir",id:"newFolder",name:"归档",parentId:""},{type:"move",id:"已有nodeToken",parentId:"newFolder"},{type:"rename",id:"已有nodeToken",name:"新标题"}]}`；根目录parentId为空字符串。新目录在飞书中为可挂子节点的空docx。只允许当前配置空间内移动、重命名、新建，不删除、不复制、不改权限。

确认：`POST /api/v3/kb/confirm {previewId,confirm:true}`。预览有效10分钟，绑定完整目录版本；写前核对codex/user/App，每一步写完重新读完整树。操作收据保存为verified/partial/aborted；同一令牌固定返回原回执。

结果不明：`GET /api/v3/kb/operations/:id`查看本地状态；`POST /api/v3/kb/operations/:id/reconcile {}`只读核实，绝不重发写入。核实部分执行后，remaining中的真实节点ID须重新预览确认。若新建响应丢失，用户在飞书明确核对新节点后才可传`{confirmObserved:true,nodeId:"实际nodeToken"}`；不按同名猜测，核不实保持空间写入锁。
