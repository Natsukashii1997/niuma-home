## 预览与操作方式

- 预览地址：页面 http://127.0.0.1:5296，API 127.0.0.1:5295，数据目录 `/tmp/workdesk-ui-v3.6nAf`（隔离副本，Voice 试运行快照照旧）。前端通过热更新拿到改动；修完后端后，核对进程、工作目录和数据目录无误，用原配置重启了 5295。
- 交互验收另起了一套一次性的测试环境：页面 5298、API 5297，数据是 `/tmp/workdesk-ui-v3.6nAf` 的副本。测试写入都落在副本里，5296 上看到的数据没有被测试改动过。验收结束后这两个服务已停掉。
- 所有写操作的用法相同：
  1. 改内容（勾选、填写、拖动、粘贴）；
  2. 点「预览…」，下方出现预览框，写清目标和改了什么，10 分钟内有效；
  3. 点「确认…」，提交并回读核对，一致才显示「已保存，回读核对一致」。
- 预览框的几种状态：
  - 改了内容：旧预览自动作废，要重新预览。
  - 后端返回 409（过期或被别处改过）：显示「预览已失效」，需要重新预览。
  - 网络中断、5xx、后端带回未结的收据：显示「结果不明，已停止」，确认按钮消失，只能「重新读取核对」，不会自动重试。
- 公共实现：
  - `src/ui/write-flow.jsx`：`useWriteFlow`、`WriteBox`、`SavedNote`；
  - `src/ui/write-flow-state.js`：失败归类的纯函数；
  - `src/ui/feishu-export.jsx`：brief 和策略导出飞书共用。

## 契约问题：已直接修复（用户 10-16 要求不再交给 Codex，由 Claude 直接改）

1. **知识库「结果尚未核实」补了错误码**：
   - 后端：未核实的情况现在统一返回 409 + `code: "KB_RESULT_UNKNOWN"` + `receipt.operationId`（`server/knowledge-tree.mjs`）。
   - 锁定时：空间被未结操作锁住，预览接口也带回那条操作的编号，页面可以直接只读核对。
   - 前端：改为按错误码判断，不再靠文案；本机浏览器只保留最近一次的编号，用作兜底。
   - 测试：`tests/v3-kb-write.test.mjs` 断言了错误码和编号。
2. **需求确认不再整份重读飞书**：
   - 改法：`needs.confirm` 改为对照最近一次时间线快照，快照缓存 10 分钟，过期会自动重读。
   - 效果：测试里从超过 30 秒降到不到 1 秒。
   - 不会漏掉来源变化：快照之后来源才变化的，同步后列表会把这条已采纳需求标成「待复核」。
   - 测试：`tests/v3-batch1.test.mjs` 改为「来源变化并同步后，旧预览确认得到 409」。
3. **Voice 合法空榜改成 200**：
   - 来源都读到、只是没有合格话题时，返回 200 + `hot: []`、`empty: true`、`note`（原因）。
   - 来源不可用仍是 503 + 错误码。
   - 前端和首页卡按空列表显示「现在没有合格的话题」。
   - 测试：`tests/v3-voice.test.mjs` 已更新。
4. **演示数据不再借 501 冒充「未实现」（顺手改）**：
   - 价格和营收改为 200 + 数据里的 `origin: "demo"`（响应头照旧）。
   - 前端 `useApi` 按 `origin` 标「示例」，标识保留。
   - 删掉了前端的 `SAMPLE_REVENUE`、`SAMPLE_PRICE_SKUS`、`SAMPLE_PRICE_SCHEMES` 兜底，演示值只在后端 `fixtures/` 里一份。
   - 本地保存过价格、而且设置里录了真实的成本和底线后，接口返回 `origin: "local"`，示例标识自动消失。
5. **仍然没有接口的按钮**：这些都显示为待实现按钮或禁用输入框，并写明原因，不假装保存。需要的话下一轮再做：
   - 时间线异常的人工裁定；
   - 手写主线需求；
   - Voice 转需求；
   - 新建项目；
   - 新开战役；
   - 战役复盘；
   - brief 附件；
   - 从数码世界导入参考；
   - NAS 原图与沿用。
