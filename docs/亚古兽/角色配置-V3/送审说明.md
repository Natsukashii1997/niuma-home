## 部署验收条件（不写进角色配置，由常浩部署时验证）

1. 员工在群聊或文档评论里，不能通过任何工具拿到常浩的私聊内容，也拿不到其他员工的受限记录（会话搜索已关，要实测）。
2. `workdesk` MCP 在技术层面限制调用的渠道和身份，不能只靠提示词要求“仅限常浩”。
3. 共享的 `USER.md`、`MEMORY.md` 里不存员工评价，也不存常浩对具体某人的私下判断。
4. 设置并实测 `terminal.cwd`，确认 HERMES.md 被加载。
