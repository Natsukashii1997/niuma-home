2026-10-16，Claude 设计。依据：

## 怎么打开

在 worktree 根目录启动一个静态服务。字体和 `src/styles.css` 需要通过 HTTP 加载，直接双击打开文件会缺字体。

```bash
python3 -m http.server 5310 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:5310/docs/design/index.html 。窗口条右侧的「自言自语」按钮可以打开右侧抽屉。

## 4. 对规范 v2 的补充和例外（需要写进 STYLE-GUIDE）

1. **画布卡片的白描边用 `#FFFFFF`**。这是用户明确要求的效果，也是全站唯一的新颜色，只用在设计参考画布上。
2. **「悬浮效果」不用阴影**。做法是在卡片右下错位 6px 放一块墨色网点，悬停时一帧跳到 9px、网点加密。
3. **弹窗遮罩**用 `--dither-ink-1` 网点，不用半透明黑。
4. **自言自语抽屉**：视口宽度 ≥ 1600 时，抽屉会把主区挤窄；小于 1600 时盖在主区上面。
5. **全局 `[hidden] { display: none !important; }`**，避免组件自己的 `display` 覆盖 hidden 属性。
6. 新增局部渐变网点 `--dither-signal-1/2`，只在「草稿」价格节点和预算条上使用。

## 5. 验证记录

- 用无头 Chromium 截了 17 个路由在 1440 宽下的全页图，控制台无报错。
- 在 820 和 390 两种宽度下，17 个路由都没有横向滚动。
- 交互实测：
  - 抽屉能打开，「转为待办」后标签更新；
  - Codex 历史弹窗；
  - 新增价格时，破底线且没填原因，「保存」不可点；填了原因就可点；不破底线时原因栏隐藏；
  - 10 小时包页面会显示破底线警告；
  - 物料大图弹窗；
  - 按国家视图；
  - 知识库勾选确认后才能同步；
  - 画布拖拽，位移按 8px 吸附。
- 规范检查：原型新增的样式里没有 transition、box-shadow、圆角、透明度和渐变；颜色只有规范色，加上第 4 节的 `#FFFFFF` 这一个例外。

**没覆盖到的地方**：
- 原型用「减少动态效果」模式截图，6 种按帧动效的过程没有逐帧截图核对；
- 原生 `<select>` 弹出的菜单没有截图；
- 全部是假数据，没有真实数据下的长文本或空状态压力测试。
