## 2. 做了什么

### ⌘K 命令面板（提案 2）

- 打开方式：任何页面按 ⌘K 或 Ctrl+K；也可以点状态栏右侧的「⌘K 命令」。
- 搜索范围（结果按这个顺序分组）：

  | 范围 | 数据来源 | 回车后 |
  |---|---|---|
  | SKU | 促销表（真实） | 打开 SKU 档案 |
  | 操作 | 固定的跳转，加上每个 SKU 一条「复制最近一个月政策」 | 复制操作直接写入剪贴板，不离开当前页 |
  | 学校 | 时间线明细表（真实） | 打开明细表，并按学校缩写筛好 |
  | 主线需求 | 交付月需求（真实） | 在用户策略里选中这条需求 |
  | 知识库文档 | 接口未实现，暂用示例并标「示例」 | 在知识库里选中这篇文档 |
  | 页面 | 19 个页面和页签 | 打开该页面 |

- 交互：↑↓ 选择，↵ 打开，Tab / ⇧Tab 切换范围，开头输入「>」只搜操作，Esc 关闭。
- 不输入时，列出最近打开的 5 项和全部页面。「最近」只存在本机浏览器里。
- 右侧预览选中项：
  - SKU：最近一个月的四项政策；
  - 学校：今天以后最近的 4 个节点；
  - 需求：时间窗、学校数、需求、痛点、状态；
  - 文档：位置、更新日期、标签、摘要。
- 第一次打开面板时才读接口，不额外拖慢页面加载。
- 原提案里的「⌘↵ 在抽屉中打开」依赖提案 4，这次不做。

### SKU 档案（提案 5）

- 路由：`#/marketing/sku/<业务线>/<SKU>`，归在营销模块下，不显示页签，页头左上角有「← 价格记录」。
- 页面从上到下：
  1. **数字条**：当前正价、交付月价格方案、首档单价、低于毛利底线的档数、价格图版本。
  2. **跨月政策表**：行是试听、正价、新签、续费、价格方案、价格图、关联需求；列从有数据的月份排到交付月。
  3. **两张并排的卡**：左边是「单价阶梯」（交付月的活动方案对比常规方案，含毛利），右边是「价格图版本」。
- 跨月表的规则：
  - 交付月那一列表头墨底；
  - 和上一个有数据的月份不同，就标「改」，悬停看旧值；
  - 交付月还没录入时，给出「去录入方案」链接。
- 入口：
  - 价格记录：工具栏里的「SKU 名 档案 →」；
  - 方案汇总：每行的 SKU 名，以及「按 SKU」分组的组头；
  - ⌘K 搜索结果。
- 数据：
  - 政策读促销表，是真实数据；
  - 价格方案读 `/api/v3/price/*`，价格图读 `/api/v3/price/charts`，这两处接口未实现时显示示例；
  - 示例只对应示例里的那个 SKU。其他 SKU 显示「价格记录里还没有这个 SKU」「价格图还对不上这个 SKU」，不借用别的 SKU 的示例；
  - 只有页面上真的显示了示例数据时，才标「示例」。

### 底部状态栏（提案 7）

- 26px，固定在底部，等宽小字。内容依次是：
  - 飞书：日报、时间线、知识库的同步或读取时间；
  - NAS；
  - Voice 预算；
  - 交付月倒计时；
  - 右侧：⌘K 入口和本机地址。
- 点的颜色：绿点表示正常，琥珀点表示有问题（悬停看原因），灰色空心点表示未接入。
- 琥珀点的判定：时间线超过 7 天没同步、NAS 连不上、Voice 预算用到 80% 以上、任一接口读取失败。
- 只写真实数据。现在的状态：
  - 时间线：显示同步时间；
  - 知识库、NAS、Voice：接口 501，显示「未接入」；
  - 日报：固定显示「未接入」。原因是 `/api/reports` 会去飞书拉文档，状态栏不应该触发外部读取。
- 让位处理：侧栏、自言自语抽屉、Agent 页、日报列表、知识库暂存条、轻提示，都让出底部这 26px。
- Codex 照旧只放在顶部横条。

## 5. 遗留问题与范围外发现

- **日报的同步时间**：用户 10-16 决定做。已派单 [V3-6](../tasks/V3-6-第三轮接口.md)，新增只读接口 `GET /api/v3/status`；同一张单里也包含价格图接口，以及第三轮依赖的已有接口要补的字段约定。Codex 完成后，Claude 把状态栏改成只读这个接口。
- **窗口条路径会露出 id**：通过深链接进入知识库时，顶部窗口条会显示文档 id（如「知识库 / c2」）。真实的飞书文档 id 很长，路径会被截断。这是 `App.jsx` 原有的 `route.slice(1, 2)` 写法造成的，这次没改。
- **价格示例不分 SKU**：价格接口在示例阶段不区分 SKU，所以国际课程的灵活学Lite 也显示大学辅导那套价格方案示例。价格记录页原来就是这样，接口实现后会自动消失。
