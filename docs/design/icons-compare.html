左边的侧栏是各方案在实际尺寸下的效果，下面的格子是放大 3 倍后的细节。A 原版、B 现版只作对照；C、D 是这次的新方案，请选一个（也可以说哪几个图标要换）。选定后全站统一替换，所有图标仍从 PixelIcon 一个入口出。

怎么选

  • A 原版 7×7：粗、实心，和像素数字、点阵很搭；缺点是只有 23 个，新模块（用户、Voice、项目、知识库）没有图标。
  • B 现版 16×16：线条细、细节多，但在侧栏里显得发虚，和像素字体不是一个重量——这是你说「不搭」的主要原因。
  • C 回到 7×7 实心并补齐（推荐）：沿用原版的粗细和实心块面，把新模块补齐，侧栏和像素数字视觉重量一致。
  • D 几何线性：不走像素风，2px 方头直线，读起来最清楚、最「普通」；整体会更像常规工具软件，位图感变弱。
