# T02 促销表细化

## 目标

在已实现的促销表（`src/modules/marketing/PromosView.jsx`：三种分组、筛选、跨月高亮）基础上，提升查看与对比效率。

## 范围

1. 分组可折叠：点分组行折叠 / 展开；分组行右侧显示「全部展开 / 全部折叠」。
2. 对比上月：高亮格子目前用 `title` 显示上月值，改为悬停浮层：显示上月月份与值，长文本保持换行。
3. 视图记忆：分组方式与筛选条件存 `localStorage`（读写都包 try/catch），刷新后保留。
4. 按 SKU 分组时，组内按月份倒序；分组标题显示该 SKU 最近一次变化的月份。
5. 表头吸顶（滚动时表头可见）。
6. 筛选「SKU」随「业务线」联动，只列出该业务线的 SKU。
7. （T01 验收遗留）`src/modules/marketing/PlanEditor.jsx`：入库成功且预览全部「无变化」后，「确认入库」置灰；修改原文或重新解析后恢复。
