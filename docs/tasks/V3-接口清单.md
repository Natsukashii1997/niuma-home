# V3 接口清单：UI 已完成，等 Codex 接上真实功能

日期：2026-10-16。UI 由 Claude 完成，在分支 `ui-v3`。这些接口目前统一走 `server/routes/v3.mjs` 的兜底，返回 501，前端会自动显示 `src/samples/v3.js` 里的示例数据，并标「示例」。

**实现方式**：
- 在对应模块的 routes 里注册具体路由。具体路由排在 v3 兜底之前，会先匹配到，所以不需要改前端。
- **返回结构按 `src/samples/v3.js` 里对应示例的结构来**，字段名和层级要一致。
- 实现一个接口，就删掉对应的示例常量，并在页面上确认「示例」标记消失。

**通用约束**：
- 隔离数据目录，真实 `data/` 只读；
- 飞书一律走 `lark-cli --profile codex --as user`；写飞书前必须先预览确认，写完回读核对；
- NAS 只读；
- 不碰主工作区和 5280；不 push。

依据：
- 需求：主工作区 `docs/需求共识-2026-10-15.md`；
- 页面：`docs/design/diagnosis/`（诊断与决定）以及本分支的实际页面。

**前端接线（Claude，2026-10-16，详见 [docs/handoff/V3-UI/README.md](../handoff/V3-UI/README.md)）**：
- 上表接口的写操作已全部接成「预览 → 确认 → 回读」。
- 成功和失败的区分：确认请求返回 409 视为预览失效；网络中断、5xx、带 `receipt` 或 `EXPORT_RESULT_UNKNOWN` 视为结果不明并锁住；回读和预览一致才算保存。
- 演示数据：`useApi` 识别 `x-workdesk-data-origin: demo`，显示后端给的演示数据，「示例」标识保留。
- 底栏：只读 `/api/v3/status`。
- 后续契约（Claude 10-16 已直接修复）：
  - 知识库「结果尚未核实」返回 409 + `code: "KB_RESULT_UNKNOWN"` + `receipt.operationId`，锁定时预览也带编号；
  - 需求确认对照最近快照；
  - Voice 合法空榜返回 200 + `hot: []`、`empty`、`note`；
  - 价格和营收的演示数据返回 200 + `origin: "demo"`。
