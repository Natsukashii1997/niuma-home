# T05 日报周报读取飞书日报文档

## 前置

- 用户提供日报文档链接（存 `settings.report_doc_url`，由 T07 的配置界面写入），并说明周报是否在同一文档。**未提供前不开工。**

## 目标

读取飞书机器人写入的日报文档，按日期列出日报 / 周报，可查看、可复制。

## 范围

1. 后端：用 `lark-cli`（`--as user`，读取文档内容的命令以 `lark-cli docs --help` 与 lark-doc skill 为准）读取文档，按文档中的日期标题切分成篇，识别日报 / 周报；结果缓存在内存，`GET /api/reports?refresh=1` 强制重读。
2. 切分规则写成纯函数 `server/report-parser.mjs`，用真实文档内容截取一段做 fixture（去掉敏感信息后放 `fixtures/`），写测试。
3. 页面 `src/modules/reports/ReportsPage.jsx` 已有骨架：加「刷新」按钮；正文尽量保留标题、列表层级（纯文本即可）。
4. 首页「最新日报」卡片自动使用真实数据。
5. 删除 `samples.js` 里的 `sampleReports`。

## 验收

- [ ] 测试：切分规则覆盖日报、周报、无日期段落。
- [ ] 手动：截图日报列表、周报列表、首页卡片，放 `docs/handoff/T05/`。
- [ ] lark-cli 未登录或文档无权限时，页面显示明确原因。

## 不做

- 不在工作台里编辑或发送日报；不读机器人私聊消息。
