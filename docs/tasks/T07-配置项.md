# T07 配置项

## 目标

提供配置界面，填写：品牌多维表格链接、日报文档链接、物料类型清单。

## 范围

1. 后端 `PUT /api/settings/:key`：只允许 `brand_base_url`、`report_doc_url`、`material_types` 三个键；链接须为 `https://` 开头的飞书域名（`feishu.cn` / `larksuite.com` 及其子域）；`material_types` 为非空字符串数组（存 JSON 字符串），去重去空。
2. 前端：侧栏底部加「设置」入口（齿轮图标，路由 `#/settings`，在 `App.jsx` 的 MODULES 之外单独放），页面三项各一个表单，保存后显示已保存的值。
3. 品牌页「配置链接」按钮跳到设置页。

## 验收

- [ ] 测试：三个键的校验（非法键、非飞书链接、空数组被拒绝）。
- [ ] 手动：配置品牌链接后品牌页出现「在飞书打开」；截图放 `docs/handoff/T07/`。

## 不做

- 不做其他配置项；不做导入导出。
