# T01 方案粘贴录入 + 规则解析 + 预览入库

## 目标

本人从飞书复制某月某业务线的促销方案，粘进工作台 → 规则解析成按 SKU 的行 → 预览（含与已有数据的差异）→ 确认后保存原文并覆盖促销行。

## 背景

- 需求：REQUIREMENTS.md「一、营销策略 → 1 方案录入、2 解析入库」。
- 页面骨架已在 `src/modules/marketing/PlanEditor.jsx`（左粘贴框、右预览示例）。
- 接口约定：docs/API.md「营销 · 方案」。
- 样例：`fixtures/2026-09-大学辅导.txt`（规整）、`fixtures/2026-09-国际课程.txt`（有空列表项、编号重复、字段在最外层）。

## 解析规则（不用 AI）

写在新文件 `server/plan-parser.mjs`，导出纯函数 `parsePlan(rawText, { aliases }) → { line, rows, unrecognized }`（对比上月等需要数据库的部分放在路由里）。

1. 含 `【…板块】` 的行 → 业务线：去掉板块两字与 emoji，取「大学辅导 / 国际课程 / 申诉服务」之一；识别不了记入 unrecognized。
2. 去掉行首的编号（`1.` `a.` `i.`）、列表符号（`*` `-` `•` `▪` `◦`）和缩进后再判断。
3. 以 `试听` / `正价` / `新签活动` / `续费活动` 开头并跟中文或英文冒号的行 → 字段。冒号后非空即为值；为空则收集其后的非空列表项，逐行用 `\n` 连接，直到遇到下一个字段或下一个 SKU。
4. 其余非空的**编号行** → 新的 SKU，名称为去掉编号后的文本；经 `sku_aliases`（同业务线）替换成库中名称，并在结果中保留 `alias`。
5. 空行、只有编号或列表符号的空项一律忽略；不依赖编号是否连续。
6. 既不是字段、也不是 SKU、也不是某字段下的列表项的非空行 → unrecognized（带行号）。
7. 未出现的字段填「无」。

## 页面

- 粘贴框：监听 paste，同时取 `text/plain`（解析用）和 `text/html`（保存用，可为空）；框内显示纯文本即可。
- 「解析预览」→ 调 `POST /api/plans/parse`，右侧显示结果：
  - 每行显示 4 个字段；`changed` 的格子用 `.changed` 高亮，悬停显示旧值；状态列用 Tag：新 SKU（orange）/ 有变化（blue）/ 无变化。
  - `alias` 存在时在 SKU 旁小字显示「原文：课时卡」。
  - `removed` 非空时列出「将删除的 SKU」。
  - `unrecognized` 非空时用 `.warn` 列出行号与原文；**有未识别行时「确认入库」不可点**，需本人修改原文后重新解析。
  - 识别出的业务线与当前页面业务线不一致时，显示警告且不可入库。
- 「确认入库」→ `PUT /api/plans/:month/:line`，成功后显示「已写入 X 行，更新 Y 行，删除 Z 行」，并刷新预览为「无变化」状态。
- 已有原文时，进入页面自动载入原文到粘贴框。
- 「复制原文」：有 `rawHtml` 时以 `text/html` + `text/plain` 双格式写入剪贴板，否则只写纯文本。
- 删除 `samples.js` 里的 `samplePlanPreview`，`PendingButton` 换成 `Button`。
