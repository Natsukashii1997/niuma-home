## 一、新接口

### 1. `GET /api/v3/price/charts?line=&sku=`：每个月这个 SKU 用的是哪一版价格图

**用在哪里**：SKU 档案的数字条「价格图」、跨月政策表的「价格图」行、「价格图版本」卡。

**返回结构**：如下（原示例 `src/samples/v3.js` 已于 2026-10-23 删除，以本文为准）。

```json
{
  "line": "大学辅导",
  "sku": "灵活学Lite",
  "versions": [
    { "month": "2026-10", "state": "file", "version": 3, "big": "4300", "path": "2026-10/产品物料/价格图/价格图-v3.jpg", "thumb": "/api/v3/nas/thumb?..." },
    { "month": "2026-11", "state": "pending", "note": "战役版 · brief 4.1" }
  ]
}
```

**字段**：

| 字段 | 说明 |
|---|---|
| `versions` | 按月份升序 |
| `state` | `file`：已有文件；`pending`：只用于交付月，表示还没有文件 |
| `version` | 版本号，从文件名的 `-vN` 读出 |
| `big` | 图上的大字，用来画示意缩略图；读不出就省略 |
| `path` | 相对 NAS 根目录的路径 |
| `thumb` | 可选。本地缩略图地址，复用 `/api/v3/nas` 那批的缩略图机制；有它页面就显示真图 |
| `note` | 可选，一句说明 |

**对应规则**：NAS 现在按「月份 / 类型」整理，不分 SKU。

1. 先实测真实 NAS 里价格图的文件名，在交接里写清楚现状。
2. 给出对应规则的建议并等用户确认：
   - 文件名里带 SKU 名的，按 SKU 名匹配；
   - 匹配不到的，要么手工登记（表结构只在 `server/db.mjs` 的 SCHEMA 里加），要么一个月只有一张价格图时算作该业务线所有 SKU 共用。
3. 用户确认之后再实现。

**其他约束**：

- 查不到这个 SKU 时，返回 `versions: []`，不要返回 404。页面会显示「还没有价格图」。
- 不在请求里扫描 NAS，只读 NAS 那批留下的扫描结果。

实现后删掉 `SAMPLE_PRICE_CHARTS`，SKU 档案上价格图部分的「示例」会自动消失。

### 2. `GET /api/v3/status`：数据源状态（只读，给底部状态栏）

**为什么要这个接口**：

- 状态栏现在为了一个同步时间，要拉 267KB 的整份时间线。
- 日报完全读不到：`/api/reports` 会去飞书拉文档，状态栏不能触发外部读取。

**返回结构**：

```json
{
  "checkedAt": "2026-10-16 20:10",
  "sources": {
    "daily":    { "state": "ok", "at": "2026-10-16 09:30" },
    "weekly":   { "state": "ok", "at": "2026-10-13 18:02" },
    "timeline": { "state": "ok", "at": "2026-10-16 19:47" },
    "kb":       { "state": "off" },
    "nas":      { "state": "error", "at": "2026-10-16 09:12", "error": "NAS 未挂载：/Volumes/营销物料", "network": "内网", "thumbBytes": 39845888 },
    "voice":    { "state": "ok", "at": "2026-10-16 10:12", "used": 3.42, "limit": 10 }
  }
}
```

**`state` 的取值**：

| 值 | 含义 |
|---|---|
| `ok` | 最近一次读取或同步成功 |
| `error` | 最近一次失败；`error` 写原因，用给用户看的中文 |
| `never` | 已经接入，但还从没成功读过 |
| `off` | 这个来源的接口还没实现 |

**`at`**：最近一次**成功**的读取或同步时间，本地时间，格式 `YYYY-MM-DD HH:mm`。失败时仍然返回上一次成功的时间。

**各来源的附加字段**：

- NAS：`network`、`thumbBytes`。用最近一次扫描的结果，不在本接口里访问 NAS 目录（挂载失效时访问会卡住）。
- Voice：`used`、`limit`，单位元，按本月计。

**硬约束**：

- 本接口**不触发任何外部读取**，包括飞书、NAS、网络。只读内存缓存和数据库，几十毫秒内返回。
- 日报、周报最近一次成功读取的时间要**写进数据库**，服务重启后仍能返回。现在日报读取器的缓存只在内存里。
- 只返回状态和时间，**不拼文案**。「还有几天」「超过 7 天没同步」这类判断由前端做（沿用二次评审 P1-5 的约定）。

**测试**：注入读取器，断言调用本接口时，飞书和 NAS 的读取函数一次都没被调用；服务重启后，日报的 `at` 仍在。

**实现后**：Claude 把状态栏改成只读这一个接口。本接口不需要示例常量，状态栏不显示示例。
