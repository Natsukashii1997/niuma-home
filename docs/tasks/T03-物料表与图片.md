# T03 物料表 + 图片上传

## 目标

物料的新建、编辑、删除、上传多张图片，并能按条件筛选、跨月对比同类物料。

## 背景

- 需求：REQUIREMENTS.md「4. 物料表」。字段：月份、业务线、物料名称、物料类型、关联 SKU（可选，多选）、图片（多张）、备注。**不含**渠道、对接人、截止日期、状态、文案、设计稿链接。
- 表结构：`materials`、`material_images`（server/db.mjs）。图片文件存 `data/images/`。
- 页面骨架：`src/modules/marketing/MaterialsView.jsx`（示例数据）。接口：docs/API.md「营销 · 物料」。

## 范围

1. 后端：实现 API.md 中物料全部接口。图片文件名用随机 id + 原扩展名；只接受 png / jpg / jpeg / webp / gif，单张不超过 20MB；`GET /api/images/:file` 防止路径穿越。删除物料时删除其图片文件。
2. 「新建物料」弹窗：月份（默认本月）、业务线、名称、类型（选项读 `settings.material_types`，未配置时用默认：海报、朋友圈图、社群海报、落地页、其他）、关联 SKU（从促销表该月该业务线的 SKU 中多选，可空）、备注。保存后可立即拖拽或选择上传多张图片。
3. 物料卡片：缩略图显示第一张图与图片张数；点击打开详情：大图浏览（左右切换）、编辑字段、增删图片、删除物料（二次确认）。
4. 「同类跨月对比」：选定类型（必要时加业务线）后切换为对比视图，每月一列，并排显示该类物料的第一张图。
5. 删除 `samples.js` 里的 `sampleMaterials`；`PendingButton` 换成 `Button`。

## 验收

- [ ] 测试（隔离数据目录）：新建、编辑、上传、删除图片、删除物料；非图片类型和超限被拒绝；路径穿越被拒绝。
- [ ] 手动：新建 2026-08、2026-09 各一个「海报」物料并上传图片，截图列表、详情、跨月对比放 `docs/handoff/T03/`。

## 不做

- 不做文案字段与「写文案」入口（文案在文案助手里聊）。
- 不做图片编辑、压缩。
