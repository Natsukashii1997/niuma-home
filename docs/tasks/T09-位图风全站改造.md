## 范围：逐页按规范精修，并接上对应交互

1. **全局**
   - 所有 `lucide-react` 图标换成 `PixelIcon`；缺的图标按 7×7 加进 `ICONS`。完成后从 `package.json` 移除 `lucide-react`。
   - 全站不得出现 `transition`、`box-shadow`、非 0 圆角（点阵圆点除外）、透明度做层级，以及蓝、绿等新颜色。
   - 可点击的卡片、列表项加 `data-dither`。
2. **营销 · 方案**
   - 方案卡片墙加网点悬停。
   - 方案录入的「解析预览」「确认入库」进行中显示 `StepProgress`（进度未知，自走），完成显示对勾，失败显示错误状态。
3. **营销 · 促销表**
   - 分组行与折叠按钮按新规范调整；悬停浮层改为直角、2px 墨框、无阴影。
   - 「与上月不同」继续用网点底加橙线。
4. **营销 · 物料**
   - 物料卡片加网点悬停；数量角标用等宽字。
   - 上传图片时用 `StepProgress` 显示**真实进度**：用 `XMLHttpRequest` 的 upload 进度事件，多张图时按已完成张数加当前进度计算；失败显示错误状态。
   - 详情弹窗按新规范：直角、2px 描边。
5. **品牌 / 业务**
   - 品牌入口卡片加网点悬停。
   - 业务页的指标骨架改用 `.kpi` 卡片，数值显示「—」，保留「待建设」；不新增数据。
6. **Agent**
   - 助手列表每项加 `BitAvatar`。
   - **正在流式输出的那条回复用 `TypeText`**：已发送、尚未收到首字时，显示空文本的方块光标；收到 delta 后逐字打出；流结束后光标消失。历史消息静态显示，不重放打字动画。
   - 模型和强度下拉框按新规范调整（下拉框样式已全局生效，只核对布局）。
7. **日/周报**
   - 点「刷新」时用 `StepProgress`（自走）；来源状态里的篇数用 `FlipNumber`。
   - 周次提示用橙框标签。
8. **设置**：周报来源「预览保存」的试读过程用 `StepProgress`。
9. **首页**：只修 bug，不改结构。如果发现数据口径问题，写进交接，由 Claude 判断。
