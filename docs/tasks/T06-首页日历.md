# T06 首页接入飞书日历

## 目标

首页「今日日程」显示本人飞书日历当天日程（只读）。

## 范围

1. 后端 `GET /api/calendar/today`：用 `lark-cli calendar +agenda`（`--as user`，参数以 `--help` 为准）取当天日程，输出 `{ time, title, place }[]`，按开始时间排序；全天日程 `time` 为「全天」。结果缓存 5 分钟。
2. 首页卡片右上加「在飞书打开」链接（飞书日历网页地址）。
3. 删除 `samples.js` 里的 `sampleCalendar`。

## 验收

- [ ] 测试：lark-cli 输出到 `{ time, title, place }` 的转换（用录下来的输出做 fixture，去掉参会人等个人信息）。
- [ ] 手动：首页截图放 `docs/handoff/T06/`；lark-cli 不可用时卡片显示原因而不是空白。
