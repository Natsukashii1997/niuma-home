# 早鸟价

**一句判断：当用户已经知道要学什么、也基本确认课程适合，却仍觉得可以晚点报名时，用真实的提前报名价差，让“现在决定”比“继续等待”更值得。**

适用业务：路觅教育大学辅导、国际课程。用途：月度用户策略选型及活动设计参考。编写日期：2026 年 10 月 20 日。

本卡依据指定手册、决策障碍词表和公开研究独立编写；未参考已有打法库草稿及审阅稿。文中业务适用性、设计规则与验证方案均为 **AI 判断或建议**，本次未取得路觅实际实验数据；情境示例不代表真实学员、学校安排或已批准活动。

## 1. 先判断：是否值得选它

**早鸟价是“提前承诺换优惠”：在指定课程的开课、上线或使用周期之前，满足公开条件的报名者获得较低价格；期限届满或真实优惠配额用完后，按已公布规则结束优惠。**

| 选型要点 | 本卡判断 |
|---|---|
| 主要解决 | **A2「觉得还来得及」**：已认可需要和课程适配，但没有现在报名的理由 |
| 有条件解决 | **B1「嫌贵」**：课程值得买，真实价差足以改变购买意愿，且优惠后仍负担得起 |
| 预期行为 | 在适配信息充分后，把报名决定提前到明确窗口内 |
| 业务价值 | 提前锁定有效报名、提高排课确定性；净新增报名是另一项待验证收益 |
| 最关键前提 | 用户已能做出知情选择；到期价可信；提前锁定对业务确有价值 |
| 不应承担 | 证明教学效果、解决课程不适配、创造学习时间，或替代家长决策 |

与相邻打法的区别：**限时折扣**只要求某段时间便宜；**早鸟价**还要求优惠与提前报名、未来交付之间存在关系。**提前锁名/占位**改变付款和承诺方式，不必包含折扣；**名额递减**强调真实容量。它们可以组合，但不能把所有限时低价都命名为早鸟价。

## 2. 它如何在用户心里起作用

**完整作用路径是：课程值得买 → 提前买确实更划算 → 等待有明确代价 → 提前承诺的风险可接受 → 做出报名决定。** 任一环节缺失，都不能靠更醒目的倒计时补上。

### 2.1 先有经济交换，才有心理推动

早鸟用户更早付款，也更早放弃一部分继续比较、等待课表或调整计划的灵活性。优惠给了用户承担这些成本的理由；路觅则希望换得更早、更可靠的需求信息。提前销售研究把未来使用价值的不确定性、容量、退款与价格可信度纳入分析，但没有证明所有提前销售都应打折，也没有给出教育业务的通用折扣率。[研究 1](https://pubsonline.informs.org/doi/abs/10.1287/mksc.20.3.219.9765)

迁移到本业务，一个有用的判断式是：

> **用户感知的真实价差＋提前安排的价值，是否足以覆盖提前付款成本、选错风险，以及继续等待的信息价值？**

这是定性分析工具，不是可以代入数字预测转化率的模型。学生还没确定选课、考试局或上课时间时，等待可能是合理决策。此时强推早鸟价，会把尚未消除的不确定性转成退课风险。

### 2.2 「现在偏好与拖延」：把远期收益连接到近期决定

学习收益通常在未来兑现，报名、付款和安排时间却要现在付出。现在偏好理论解释了：在某些条件下，人会反复推迟这类“当下付出、以后获益”的行动。[研究 2](https://www.aeaweb.org/articles?id=10.1257/aer.89.1.103)

**本卡推断：** 对已确认适配的用户，早鸟价通过真实的到期价差，让“晚点再说”不再看起来没有成本。改变的是购买时点的比较，而不是让学习需求凭空变强。

因此，A2 的识别不能只看“咨询后没付钱”。需要进一步确认：未付款是因为不急，还是还在等课程信息、资金、课表或决策人。只有前者才支持优先采用这条机制。付款提前也不证明学习开始得更早，更不证明成绩改善。

### 2.3 「交易效用」：既判断课程值不值，也判断此时买划不划算

交易效用理论区分产品本身的价值与相对参考价格的“划算感”。即使课程内容不变，可信价差也可能改变用户对这笔交易的评价。[研究 3](https://pubsonline.informs.org/doi/abs/10.1287/mksc.4.3.199)

**本卡推断：** 应同时呈现同一课程、同一权益的早鸟价、优惠结束后的价格和实际差额。只展示折扣，用户可能知道“便宜”，仍不知道“是否值得”；拿不同课时、不同服务或虚高标价作比较，则无法支撑可信的购买理由。

这解释了 B1 的适用边界：“嫌贵”可能是觉得价值不足，也可能是眼下付不起。前者需要课程价值证据，后者需要可负担的方案；小幅优惠不一定解决其中任何一种。

### 2.4 「参考依赖与损失厌恶」只能作为条件性解释

当用户把当前优惠视为自己能够获得的机会时，优惠到期可能被体验为“失去这次价差”，从而增强行动意愿。前景理论为参考点附近的得失评价提供了基础，但原研究针对风险选择，不能直接证明“不报名就损失优惠”在课程销售中成立。[研究 4](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Behavioral_Decision_Theory/Kahneman_Tversky_1979_Prospect_theory.pdf)

**不能直接把未获得折扣等同于真实损失。** 用户若预计下次优惠更大，或根本不确定要买这门课，就可能不接受这个参考点。因此，本卡不采用“损失厌恶必然促成交”或固定效果倍数，也不把怕错过当作唯一机制。

### 2.5 截止时间是规则与触发条件，可信度决定其能否成立

明确截止时间能让用户知道何时必须完成决定，但“限时”本身不是效果保证。线上零售研究发现，线下限时促销的积极效果未必在线上重现，用户还可能识别出商家的催促意图；研究不支持限时促销稳定优于同等对照。[研究 5](https://journals.sagepub.com/doi/abs/10.1177/00222437221118856)

**本卡推断：** 将截止与真实开课、测评和排课安排相联系，比随意写“今晚最后一天”更容易解释。但这不是上述研究已经验证的教育结论。反复延期、到期仍给同价，会削弱下次提前报名的理由；若用户主要担心买错，更短期限还可能使其退出决策。

## 3. 什么时候用，什么时候换打法

**三个条件同时成立，才把早鸟价列为主打法候选：需求和适配已基本确认；主要阻力是购买时点或可被价差改变的价格判断；业务能兑现价格及交付承诺。**

下表的用户表达均为识别示例，不是路觅真实原声。

| 观察到的信号 | 对应障碍 | 选型判断 |
|---|---|---|
| 已看过课纲、确认时间，仍表示“离考试还早，过阵子再报” | A2 觉得还来得及 | 优先候选；先核实没有其他未解决条件 |
| 认可课程，也能付款，但明确在比较实际总价 | B1 嫌贵 | 条件适用；检验价差是否改变决定，不能默认全员发优惠 |
| 反复追问老师能否讲懂、是否适合自己 | A3 不信任效果／B2 怕选错 | 先诊断、试听或澄清班型，再判断是否需要早鸟 |
| 尚未确认选课、课表或家长意见 | B2 怕选错／B4 需要家长同意 | 暂缓；先补信息和共同决策，不能用截止替代 |
| 想学但近期根本排不出学习时间 | B3 没时间 | 优先调整交付形式或周期，降价不会增加可用时间 |
| 认为无需辅导、替代资源已经够用，或从未了解过路觅 | A1 没意识到需要／A4 有替代品／C1 没被触达 / 不知道我们能帮 | 早鸟不是首要动作；分别先做需求识别、差异化证明或有效触达 |

**即使用户适配，以下经营条件也应否决或暂缓：** 按原价已大概率满班，且提前锁定没有足够额外价值；课程方案尚不稳定；到期恢复价格无法统一执行；优惠后不能覆盖相应交付成本。缺证据时先核实，不以“促销总会多卖一点”代替判断。

## 4. 放进月度策略：两条推导示例

**时间节点必须来自真实学校、考试或课程安排，不能从“本月想做早鸟”倒推学生需求。** 以下为假设情境；实际月份、地区、日期和用户障碍需另行取证。

| 推导环节 | 大学辅导：期末复习班 | 国际课程：阶段备考班 |
|---|---|---|
| 时间节点 | 考试日程已公布，复习班尚未开课 | 考试季及报考科目已确认，阶段班尚未开课 |
| 待办任务 | 排定复习计划，完成重点章节练习 | 按考试局要求，安排目标科目的阶段备考 |
| 核心痛点 | 知识薄弱点分散，难以安排复习顺序 | 已识别知识缺口，缺少系统练习与反馈 |
| 决策障碍 | A2：认可课程，但认为再晚些报名也来得及 | A2：学生与付款人已认可方案，仍想晚些决定 |
| 心理机制 | 现在偏好与拖延；交易效用 | 现在偏好与拖延；交易效用 |
| 打法与作用路径 | 早鸟价：使继续等待产生真实价差，促成开班前报名 | 早鸟价：以明确报名窗口推动已形成共识的方案落实 |
| 推翻选择的证据 | 实际还没确认考试范围或课程匹配，应转向 B2 | 家长仍未同意，应转向 B4；科目或考试局未定，应转向 B2 |

大学辅导须核对学校、课程代码、教学范围及当地课表。国际课程须核对课程体系、考试局、科目、考季，以及学习者与付款决策者是否一致；不能套用海外大学时间线。

**交付形态决定可采用的变体：**

| 交付形态 | 使用条件与关键设计 |
|---|---|
| 直播班课、训练营 | 有确定开班日和交付安排，适合建立提前报名窗口；班级总容量与优惠配额分开说明 |
| 1v1 | 先确认师资、科目和可约时段；仅购买课包不等于锁定某位老师或黄金时段 |
| 录播课 | 新课预售或明确的新学习周期可用；常年即时可学的存量课，普通限时折扣通常更贴切 |
| 会员、题库 | 新版本预售或到期前续订可考虑；写清开通与有效期起算，不能让提前购买侵蚀原有权益 |

上述适配判断均待业务验证。数字内容容易复制，不代表答疑、批改和教师服务容量无限。

## 5. 如何设计：先定交易，再定截止，最后定提醒

**最小版本只保留“一门明确课程、一个早鸟价格、一个明确结束条件”。** 先验证主要机制，再考虑增加阶梯、名额或加赠。

| 设计项 | 必须明确的规则 | 设计理由与失败信号 |
|---|---|---|
| 适用对象 | 指定课程、班次、购买资格，新签与续费是否同规则 | 条件公开且一致；不要按用户焦虑程度临时改价 |
| 提前购买的价值 | 学员获得什么；业务为什么需要提前确认 | 若只能解释为月底冲业绩，尚不足以证明值得付出折扣成本 |
| 价格与权益 | 早鸟价、到期价、实付差额；课时、服务、有效期和可叠加优惠 | 同口径比较；宣传页、咨询报价和支付页一致 |
| 报名窗口 | 起止日期、时间、时区；截止时必须完成的动作 | 从“信息已足够”到“排课需确定”倒推，不直接套固定提前周数 |
| 支付边界 | 按付款成功还是订单创建判定；支付异常和未付订单如何处理 | 避免用户已按时操作却因规则不明失去资格 |
| 优惠配额 | 是否真的限额；用完与到期是否先到先止；退款是否释放配额 | 不需要限额时，只设截止时间；优惠配额不冒充课程剩余席位 |
| 提前承诺风险 | 课纲、师资安排、上课时间、成班条件、退改及延期处理 | 信息缺失先补齐；仅展示已经确认且能够履行的政策 |
| 后续价格 | 同课程后续促销、渠道优惠、老客权益如何衔接 | 若已计划更低到手价，先处理冲突，不能隐瞒后继续强调早买划算 |
| 到期与例外 | 谁核对价格切换；哪些有据可查的异常按什么规则处理 | 不悄悄续期；平台故障等例外保留证据并统一处理 |

**折扣没有可直接套用的标准答案。** 原手册写作“75–85 折”，单位存在歧义；即使本意为 7.5–8.5 折，也未提供适用条件、研究或经营数据，本文不将其作为推荐区间。实际价格应结合原价购买基线、容量、退款、服务成本和可承受让利测算，由定价责任人确认。

最低经营核算应同时回答两件事：优惠订单自身是否有合理贡献；相对不做早鸟，增加的贡献及可核验的排课收益，能否覆盖原价订单转优惠的损失和新增活动成本。前一项为正，不代表后一项也为正。

### 最小执行顺序

1. **选对象。** 策略负责人核实时间线及 A2/B1 证据，形成候选课程和人群，不把所有未付费者等同于拖延者。
2. **锁规则。** 产品与教务确认适配信息、容量、排课和退改；定价责任人确认价差、叠加和成本；指定一名活动负责人承接异常。
3. **验证后上线。** 运营核对展示与支付口径，并检查资格、截止、时区、叠加及异常处理。先提供决策信息，再向相关用户发截止提醒。
4. **到期回读。** 活动负责人核对宣传和实付价格均已切换；已完成报名者停止催购，进入测评、排课或开课通知。
5. **按完整周期复盘。** 到常规招生结束并经过约定退款观察期，再判断报名增量与经营结果；开课后的到课另行核验。

这是执行角色建议，不是已确认的团队分工，也不表示活动已经获准上线。

### 与其他打法组合时，只补真实缺口

- **先试听，再早鸟：** 用于 A3/B2 尚未解决的人群；试听后仍有合理决策时间。
- **早鸟＋价保：** 用于有证据表明用户担心后续更低价的情形；先定义同课程、同权益、适用窗口和补差方式。
- **早鸟＋提前锁名/占位：** 仅在真实支付或排课需求下采用；总价、尾款、未付尾款及退改规则必须清楚，不能把占位人数算作有效报名。
- **早鸟＋涨价预告／倒计时：** 两者用于传达同一个真实结束条件，不把重复表达当成三种独立增长来源。

默认不同时叠加定金膨胀、券、抽奖和多档阶梯。规则负担可能增加 B2「怕选错」，也会使策略效果难以归因。以上为设计判断，组合效果尚待验证。

## 6. 如何验证：分清提前、增量和代价

**优先验证“有效报名是否提前”，再分别检验增量和经营价值。** 不把早鸟期成交增长、付款截图或倒计时点击率当作最终成功。

建议活动前固定合格人群、分组方式、统计单位、完整观察窗口和可接受代价。合格人群按活动开始前的课程适配及目标条件确定；不能事后只留下看过优惠或已经付款的人。

| 要回答的问题 | 建议指标与口径 | 能证明什么、不能证明什么 |
|---|---|---|
| 是否提前锁定 | 截止日前完成约定付款，且在统一观察期后仍有效的去重学员数／预先确定的合格用户数 | 可比较提前锁定率；不能单独证明全周期新增 |
| 目标课程是否有增量 | 完整招生周期内净有效报名人数／预先确定的合格用户数；以未取消且达到约定付款条件为准 | 比较同口径对照差异；新签与续费分别统计，不能据此声称业务整体增长 |
| 经营上是否值得 | 每名合格用户的净贡献差异 | 净实收扣除交付、服务、渠道及活动等相关成本；计入因加开班次新增的固定成本，不把收款额当利润 |
| 是否改善排课 | 在预定排课节点已确认的人数、临时调班与撤班成本 | 只有实际减少排课不确定性或成本，才能报告运营收益 |
| 是否透支质量或信任 | 退款／退课、到课、价格投诉、排课失败、后续等待促销的反馈 | 与同口径基线比较；付款提前不能替代交付或学习效果验收 |

目标课程增量与业务净增量应分开：还需观察同一合格人群在相关替代课程、班型和渠道的购买与贡献变化。例如正常价 1v1 转为早鸟训练营，可能只是购买迁移；跨课程去重不能消除这种替代影响。

**对照建议：** 在公开规则、用户体验和执行条件允许时，在预先确定的合格人群或可比班次中随机分配方案；两组保持课程、适配信息、触达频次与服务一致，区别在早鸟价格安排。采用班次分组时须按班次层级评估，不能把同班学员当作独立随机样本。跨群传播和满班相互挤占会污染比较，应记录并限制因果结论。若对照组完全未被提醒，测到的是整套促销与触达的合并效果，不能单独归因于价格。

观察必须跨过常规招生结束，并给两组相同的退款观察时长。无法随机分配时，记录原有购买意愿、季节、课程及流量来源等差异和识别假设；可比人群或历史班次也不能自动排除选择偏差。未经充分控制的结果仅作描述性比较，不归因为早鸟价的效果。样本不足或差异不明确时保留未知，不宣称有效或无效。

**结果如何改变决策：**

- 提前锁定增加，全周期报名无明显变化：只能报告购买时点前移；若排课收益足以覆盖让利，仍可能值得保留。
- 全周期净报名增加，但净贡献下降：检查原价订单让利、获客质量和交付扩容成本，不能只凭订单量扩大活动。
- 咨询增加，适配疑问和退课增加：优先处理 B2/A3 与提前承诺风险，不继续缩短期限。
- 出现虚假名额、价格不一致或交付承诺无法兑现：暂停相关新增销售并核对处理；这是执行底线，不等待实验结束。

业务验收门槛应在活动前由负责人结合基线确定，包括最低可接受贡献、退款及交付风险上限。本卡不虚构统一提升百分比。

## 7. 月度策略可直接引用的表达

> 对已确认课程适配、主要卡在 A2「觉得还来得及」的用户，采用早鸟价作为提前报名候选。作用路径是：现在偏好与拖延／交易效用 → 可信价差使等待成本可见 → 推动开班前决定。先核实课纲、排期和到期价；A3、B2、B4 未解决者先补信息。验证提前锁定率，并另看全周期净报名与净贡献。

实际使用时补上已核实的地区、课程和时间窗。这段只表达选型理由，不替代定价、活动审批或效果结论。

## 附：约 55 种打法建议采用的统一卡片结构

**建议统一“需要回答的问题”，不统一成长表格，也不要求每张卡写成相同篇幅。** 采用“选型摘要＋机制与设计正文＋证据尾注”：月度策略编写者先筛选少量候选，选中后再读执行细节。

### 八个固定模块

| 模块 | 最小内容 | 为什么保留 |
|---|---|---|
| 1. 定义与一句判断 | 标准名称、改变的交易条件或用户行为、与近似打法的区别 | 避免把倒计时、折扣、预售混成一个概念 |
| 2. 选型摘要 | 主障碍编号、条件适用障碍、目标行为、关键前提、最强否决条件 | 支持从“障碍”检索打法，而不是从活动名称反推需求 |
| 3. 心理与行为机制 | 用户原来的判断 → 打法改变了什么 → 判断如何变化 → 预期行动；注明成立条件和反作用 | 防止只贴“损失厌恶、稀缺”等标签，缺少因果解释 |
| 4. 适用信号与业务情境 | 可观察信号、反证；至少一条完整策略推导链；必要的业务线或交付差异 | 把理论接到真实选择，防止把假设案例写成用户事实 |
| 5. 最小设计与执行 | 必填参数、先后依赖、角色、触发及结束规则、异常处理、最小实例 | 让使用者知道还需确认什么，避免拿卡片直接拼海报 |
| 6. 组合与替代 | 何时先做另一打法、何时补充、何时互相冲突 | 组合必须对应剩余障碍，不能把优惠越叠越多当成策略 |
| 7. 验证与退出 | 主指标、固定分母、观察窗口、对照、成本与质量护栏、继续／调整／停止条件 | 区分机制信号、真实增量和经营价值 |
| 8. 来源与状态 | 原始手册、研究出处、业务证据、推断和未知、版本与适用边界 | 使“有理论依据”和“路觅已经验证”始终可分辨 |

### 三条编写规则

**第一，障碍标签分强弱，机制名称保持一致。** 每张卡明确主障碍，只有能说明条件与路径时才增加辅助障碍；不为了检索覆盖而把九项全挂上。区分心理机制、活动规则和执行手段：“交易效用”是机制，“到期恢复价格”是规则，“倒计时”是传达手段。全库共用机制释义，卡内只展开其在本打法中的作用和边界。

**第二，保留共同骨架，按打法补充专属参数。** 价格类重点补价差、叠加和利润；权益类补交付成本和使用条件；支付类补付款义务与失败处理；信任保障类补承诺范围和兑现流程；会员续费类补有效期、使用及续订规则。没有对应依赖的字段不强行填满。

**第三，把卡片、月度策略和活动方案分开维护。** 卡片保存稳定原理与适用边界；月度策略填写当月人群、节点、障碍证据和选择理由；活动方案填写实际价格、日期、责任人及执行规则；复盘证据回链到卡片。未验证的规律维持“待验证”，出现相反证据时收窄适用范围。

建议每张卡保留一条可供月度策略引用的短表达，但具体日期、学校、价格和临时政策不固化在打法正文中。本样卡展开较多，是为了示范机制深度和证据边界；全库不需要机械复制全部篇幅。

**研究依据**（题名为中文译述，链接对应原文；不引用任何普适转化提升数字）

1. **Xie, J.；Shugan, S. M.（2001）**，《电子票、智能卡与在线预付款：何时及如何提前销售》，《营销科学》20(3)，219–243。[期刊原文](https://pubsonline.informs.org/doi/abs/10.1287/mksc.20.3.219.9765)。理论模型支持提前销售需考虑未来价值不确定性、容量、退款和价格可信度；不证明路觅采用早鸟价就会增利。
2. **O’Donoghue, T.；Rabin, M.（1999）**，《现在做，还是以后做》，《美国经济评论》89(1)，103–124。[期刊原文](https://www.aeaweb.org/articles?id=10.1257/aer.89.1.103)。解释现在偏好与拖延的条件；不是教育促销实验，不支持把所有观望者判为拖延者。
