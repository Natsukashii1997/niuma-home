这版怎么定的

线上这里是「三条业务线」卡，样稿借位写说明
  1. 每点数值：今年墨色、去年灰色，同一列谁高谁往上标、低的往下标。点挨得近或折线穿过数字时，标签在点四周换 8 个位置找空地；实在放不下的就不画，悬停卡里能看到。数字套一圈面板底色描边，压在网点列和折线上也不糊。
  2. 竖线与方框：移进图里，离鼠标最近的一列出现墨色点线，这一列每个点套一个方框（今年同线色、去年灰、推算橙），月份反色。
  3. 数据卡：弹在竖线右边，右边放不下换左边，始终在图框里。直角、2px 墨框，右下错位 6px 墨色网点（同书架悬停卡），不用阴影。一线一行，前面的方点照图上画法：实心今年、空心至今、橙色虚框推算、灰色小点去年；金额写万元一位小数，下面一行精确到分的元（原来鼠标停在点上才看得到）；底行同比，涨绿跌红。
  4. 键盘：Tab 到图上默认停在当月，← → 逐月，Home / End 到头尾，Esc 收起；焦点框沿用全站橙色。
  5. 不加动效：竖线和卡片随列跳，不滑、不渐显。
