# 用户策略 · 促销策略内部匹配逻辑

2026-10-20 与用户确认，取代原来由本机 Codex 生成促销策略的做法。本文写清匹配逻辑现在怎么工作、依据是什么、哪些地方还不确定，供 Codex 检查和优化。规范总纲见 [用户策略规范.md](用户策略规范.md) 第 7 节；打法卡片见 [打法库/](打法库/README.md)（飞书阅读版：《打法库（含心理机制）》）。

## 1. 目标与边界

- **做什么**：输入某个月已确认的用户洞察，输出这个月的促销策略：本月目标、核心打法，以及第 4 段（4.1 打法组合、4.2 选择逻辑、4.3 不选什么、4.4 底线）。
- **怎么做**：规则匹配，不调用任何模型。同一份用户洞察，输出完全相同；点按钮约 0.1 秒出预览。
- **范围**：只覆盖大学辅导，不含申诉服务；不定具体价格（定价归价格模块）。
- **推导链路**：决策障碍 → 心理机制 → 打法。打法针对的是购买障碍，不是学业痛点。
- **代码**：`server/user-strategy.mjs` 的 `matchPromo(doc, cards)`；打法优先表在 `src/modules/user/playbook.js` 的 `PRIORITY`；输出由同文件的 `checkPromo` 校验；测试在 `tests/v3-user-strategy.test.mjs`（`npm test`）。

## 2. 输入

| 来源 | 用到的字段 |
|---|---|
| 用户洞察 `docs/用户情况/YYYY-MM.json` | 7 个地区的分档（主战场 / 次要 / 平稳）、决策障碍（词表编号 + 一句具体描述）、机会点（末尾带窗口日期）；机会收敛（P0 / P1 / P2、新签 / 续费） |
| 打法卡片 `docs/打法库/P*.md` | 第二行隐藏元信息：阶段（新签 / 续费 / 通用）、主障碍、辅障碍、心理机制（第一个是主机制）；正文「不宜组合的情况」一段 |
| 决策障碍词表 `playbook.js` 的 `BARRIERS` | 9 个障碍，按动机不足 A1–A4、能力受限 B1–B4、触发缺失 C1 排序 |
| 心理机制词表 `playbook.js` 的 `MECHANISMS` | 机制名 + 一句标准释义 |

## 3. 匹配规则（按执行顺序）

1. **障碍权重**：把每个地区的每个决策障碍按该地区分档计分并累加，主战场 3、次要 2、平稳 1。
2. **障碍排序**：权重高的在前；同分时先比涉及的主战场地区数，再按词表顺序（A1 → C1）。
3. **分栏**：
   - 新签栏只从阶段为「新签」或「通用」的卡里选；续费栏只从「续费」或「通用」里选。
   - 续费栏不处理「不信任效果」「没被触达」，理由是老学员已经买过、已在触达范围内。
4. **逐个障碍选卡**：
   - 按排序依次处理每个障碍，从该障碍在优先表里的候选中，取第一张同时满足三个条件的卡：阶段合适、本栏还没选过、不与本栏已选的卡冲突。
   - 本栏第一张为「主打法」，其余为「辅助」。
   - 每栏最多 4 张。一个障碍如果已经是某张已选卡的主障碍，就不再单独选卡。
5. **冲突**：
   - **不宜组合**：A 卡正文「不宜组合的情况」一段里出现了 B 卡的名称（含「/」拆开后的短名，长度不小于 2），A、B 就不进同一栏，判断是双向的。
   - **直接降价**：同一栏最多一种。直接降价指限时折扣、直降 / 立减、支付立减、早鸟价、阶梯降价。
6. **4.3 不选什么**（最多 3 条）：
   - 因冲突被跳过的候选卡，理由写「与 X 不宜组合」或「本栏已有 X，同栏只用一种直接降价」。
   - 某障碍的首选卡没用上、因为该障碍已被其他卡覆盖的，理由写「已由 X 覆盖，只补真实缺口」。
   - 因每栏最多 4 张没轮到的障碍，它的首选卡理由写「只涉及某地区，本栏已满 4 张」。
   - 以上不足 2 条时（如 2026-01 没有任何冲突和覆盖），补已选障碍的第二候选，理由写「已用 X，不再叠加同类打法」。
7. **4.4 底线**：固定三条。
   - 毛利：同一订单只叠加一种让利，加赠按成本价计入毛利。
   - 价格锚点：老学员价 ≤ 早鸟价 ≤ 限时价 / 立减价 < 正价，违反不上线。
   - 合规：不承诺成绩与通过率；退款、价保等条款写明期限。

## 4. 打法优先表（`PRIORITY`）

每个障碍的候选按顺序排列，靠前的先选。依据是规范第 6 节「打法方向」，加上各卡片的定位。表里没有列出的障碍，这一栏不会为它选卡。

**新签栏**

| 障碍 | 候选（按优先级） |
|---|---|
| 没意识到需要 | 免费学业诊断 / 测评 → 免费试听 / 公开课 |
| 觉得还来得及 | 早鸟价 → 涨价预告 → 封班 / 截止报名 → 定金预售 |
| 不信任效果 | 免费试听 / 公开课 → 7 天无理由退 → 学习保障条款 → 低价引流课 |
| 有替代品 | 赠 1v1 课时 / 答疑 → 正课 + 服务打包 |
| 嫌贵 | 满额加赠门槛 → 分期免息 → 赠题库 / 会员 |
| 怕选错 | 免费学业诊断 / 测评 → 班型梯度 |
| 没时间 | 自选课包 → 赠伴学 / 督学服务 |
| 需要家长同意 | 学习保障条款 → 班型梯度 |
| 没被触达 | 渠道专属权益 → 新客无门槛券 |

**续费栏**

| 障碍 | 候选（按优先级） |
|---|---|
| 没意识到需要 | 免费学业诊断 / 测评 |
| 觉得还来得及 | 早鸟价 → 价保 → 定金预售 |
| 有替代品 | 积分体系 → 学习会员 |
| 嫌贵 | 老学员续报价 → 连报优惠 → 学习会员 |
| 怕选错 | 多科联报 → 全程班 |
| 没时间 | 自选课包 |
| 需要家长同意 | 全程班 |

**取舍说明**

- 「觉得还来得及」不用阶梯降价。按卡片定义，阶梯降价从体验课结课开始计时，不适合「按距 Final 天数」分档；时间杠杆用早鸟价加涨价预告。
- 「觉得还来得及」也不用限时折扣。它在早鸟价卡片的「不宜组合」里被点名，而且会强化双 11、黑五带来的「等折扣」预期。
- 「嫌贵」新签栏优先用加赠和分期，不用直降。依据是规范第 6 节「加赠、满额赠、分期」。
- 「没时间」没有任何卡把它当主障碍，只能从辅障碍里取：自选课包（对应「按考点打包」）和赠伴学 / 督学服务。

## 5. 卡片里解析出的「不宜组合」（共 28 对）

早鸟价 ✕ 限时折扣；阶梯降价 ✕ 早鸟价；前 N 名加赠 ✕ 报名抽奖；涨价预告 ✕ 限时折扣；满额加赠门槛 ✕ 满减；连报优惠 ✕ 全程班；多科联报 ✕ 满减；自选课包 ✕ 满减；班型梯度 ✕ 自选课包；加价升级（Upsell）✕ 满减；正课 + 服务打包 ✕ 全程班；全程班 ✕ 连报优惠；赠 1v1 课时 / 答疑 ✕ 班型梯度；赠教辅 / 讲义 ✕ 7 天无理由退；低价引流课 ✕ 新客无门槛券；分期免息 ✕ 直降 / 立减；分期免息 ✕ 支付立减；学习会员 ✕ 赠题库 / 会员；学员等级 ✕ 赠题库 / 会员；积分体系 ✕ 赠题库 / 会员；新客无门槛券 ✕ 早鸟价；新客无门槛券 ✕ 低价引流课；弃购挽回 ✕ 沉睡召回券；渠道专属权益 ✕ 红包雨 / 整点红包；报名抽奖 ✕ 前 N 名加赠；报名抽奖 ✕ 红包雨 / 整点红包；红包雨 / 整点红包 ✕ 报名抽奖；集卡 / 闯关 ✕ 红包雨 / 整点红包。

## 6. 文字怎么拼

| 位置 | 模板 |
|---|---|
| 本月目标 | 新签以〔新签主打法〕主攻〔P0 机会名，用顿号连接〕；续费以〔续费主打法〕承接〔第一个续费机会名〕 |
| 核心打法 | 〔主打法〕：化解「〔障碍名〕」（〔涉及地区〕） |
| 4.1 做法 | 针对「〔障碍名〕」：〔权重最高地区对该障碍的具体描述〕，超过 40 字截断 |
| 4.1 适用 | 〔涉及地区〕 · 〔这些地区所有机会点窗口的并集〕 |
| 4.2 作用路径 | 主机制在心理机制词表里的标准释义 |

## 7. 示例：2026-11

**障碍权重**

| 障碍 | 权重 | 涉及地区 |
|---|---|---|
| 没时间 | 8 | 美国（主战场）、澳洲（主战场）、新加坡（次要） |
| 不信任效果 | 8 | 美国（主战场）、澳洲（主战场）、新加坡（次要） |
| 觉得还来得及 | 7 | 英国（主战场）、香港（次要）、加拿大（次要） |
| 有替代品 | 6 | 英国（主战场）、美国（主战场） |
| 嫌贵 | 5 | 英国（主战场）、加拿大（次要） |
| 没被触达 | 4 | 澳洲（主战场）、其他（平稳） |
| 怕选错 | 2 | 香港（次要） |

「没时间」与「不信任效果」同分，主战场地区数也相同，按词表顺序 A3 在 B3 前，所以新签栏先处理「不信任效果」。

**输出**

- 本月目标：新签以免费试听 / 公开课主攻期末冲刺、结课作业与 1 月备考；续费以自选课包承接下学期续报。
- 新签栏：
  - 主打法：免费试听 / 公开课（不信任效果）
  - 辅助：自选课包（没时间）、早鸟价（觉得还来得及）、赠 1v1 课时 / 答疑（有替代品）
  - 「嫌贵」「没被触达」「怕选错」因每栏最多 4 张没有轮到。
- 续费栏：
  - 主打法：自选课包（没时间）
  - 辅助：早鸟价（觉得还来得及）、积分体系（有替代品）、多科联报（怕选错）
- 4.2 举例：
  - 不信任效果 → 权威效应 → 免费试听 / 公开课 →「名师、专家的判断被视为可信」
  - 觉得还来得及 → 现时偏差 → 早鸟价 →「人倾向于把决定往后拖，截止期把以后再报拉到现在」
- 4.3：
  - 满额加赠门槛：「嫌贵」已由自选课包覆盖
  - 老学员续报价：「嫌贵」已由自选课包覆盖

## 8. 已知问题，请重点检查

1. **优先表是人工排的**：决定选哪张卡的主要是优先表，卡片标签只决定哪些卡有资格入选。顺序是否合理、是否漏了更合适的卡，需要逐个障碍复核。
2. **没有用到时间信号**：卡片「适用信号」里写了时间条件，比如早鸟价要求距开课 4–8 周、距需求高峰至少 3 周，但目前没有拿这些条件去对照当月节点。所以 Final 只剩 1 周的地区也可能被配到早鸟价。
3. **续费栏借用了新签的障碍**：用户洞察只写了潜在新用户的障碍。续费栏只是去掉「不信任效果」「没被触达」后直接沿用，老学员特有的障碍（如「上学期效果一般」）没有数据来源。
4. **主打法与核心打法相同**：续费栏的主打法常常和新签栏的某张辅助卡相同（如 11 月的自选课包、早鸟价）。是否需要两栏错开，待定。
5. **「不宜组合」靠名称匹配**：
   - 别称会漏。例如早鸟价写的是「多档阶梯同时叠加」，没能匹配到「阶梯降价」；这一对能识别出来，是因为阶梯降价那张卡点了早鸟价的名。
   - 顺带提到的名称会误判。例如「赠 1v1 ✕ 班型梯度」需要回卡片原文确认，是不是真的不宜组合。
6. **直接降价名单写死在代码里**：5 张卡的名单不是卡片标签，新增卡片时要人工同步。
7. **作用路径偏泛**：用的是机制的通用释义，没有结合具体打法和当月场景。比如赠 1v1 走「后悔规避」，释义写的是「怕选错就不行动」，和「有替代品」这个障碍对不上。
8. **每栏最多 4 张、按权重截断**：低权重地区的障碍（如 11 月香港的「怕选错」）在新签栏没有轮到，在续费栏却被选上，两栏的覆盖不一致。
9. **适用窗口太宽**：取的是涉及地区所有机会点窗口的并集（如 11/01–12/22），没有对应到打法本身该上线的时段。
10. **4.4 是固定文字**：没有随当月选中的打法变化。比如选中价保时，应补一条价保窗口的要求。

## 9. 改动约束

- 输出结构必须通过 `checkPromo`：
  - 4.1 两栏各 1 行以上，每行是 `[角色, [打法编号], 做法, 适用]`。
  - 4.2 每行是 `[障碍编号, 栏, [机制编号], [打法编号], 作用路径]`。
  - 4.3 每行是 `[[打法编号], 理由]`；4.4 每行是 `[标题, 内容]`。
- 写作规范：单条不超过 40 字（本月目标不超过 70 字），正文不写编号，不用禁用词。超出只记为提示，不拦截。
- 改了规则要同步更新本文、`docs/用户策略规范.md` 第 7 节和测试；`npm test` 必须全部通过。
