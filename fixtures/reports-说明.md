## T05B 周报样例

- `weekly-real-redacted.md`：2026-10-14 通过 codex 应用的 user 身份只读获取独立周报文档（revision 497），共 21 个二级周报标题；截取最新第 41、40 周，以及另一篇跨月的第 36 周。原标题和日期保留，正文、小标题、表格单元格文本均替换为 `[内容已脱敏]`，最多保留首张表格两行结构，其余省略；未保存完整业务正文或嵌入资源。
- `weekly-boundaries.md`：人工构造，覆盖跨月、两种跨年、括号和分隔符、空白、闰日与七天边界、无效日期、逆向及八天范围、周次与 ISO 周年提示、代码块与子标题。
- 改动前日报 ID 基线已固定在 `tests/weekly-reports.test.mjs`，两个既有 fixture 共四个 ID（含一篇旧格式周报）在改动后必须完全一致。

规则：日期标题支持 `YYYY-MM-DD`、`YYYY/M/D`、`YYYY年M月D日`；标题以日期或「日报 / 周报 + 日期」开头，可带前导图标。取有效日期标题中最浅的标题层级为报告层级，较深标题留在正文，同层或更浅的非日期标题结束当前篇。含「周报」的日期标题归为周报，其他归为日报；范围采用首个日期排序。同日多篇保留，以标题和出现次序生成 ID，正文修改和新增其他日期不影响 ID。源文档如调整标题或同标题重复段的顺序，原深链可能变化。

正文保留 Markdown 标题、列表缩进；HTML 表格逐行转换为竖线分隔的单元格文字。页面按纯文本显示，不执行 HTML。没有日期标题的说明不单独生成报告。
