# T05 解析验收样例

- `reports-real-redacted.md`：2026-10-14 通过用户提供的飞书文档（revision 1350）截取 2026-10-13、2026-10-12 两篇日报的日期标题、首个小标题和表格首行；保留原始 HTML 表结构，任务、人名、出处、业务主题均替换为 `[内容已脱敏]`，其余正文省略。开头无日期说明为测试补充。
- `reports-boundaries.md`：人工构造的边界测试，不代表源文档已有周报。覆盖显式周报日期范围、无日期段落、子标题、列表缩进和无效日期。

当前真实文档有 126 个日期标题，均为日报，未发现独立周报标题。真实周报验证需待源文档新增周报或用户指出对应标题。

规则：日期标题支持 `YYYY-MM-DD`、`YYYY/M/D`、`YYYY年M月D日`；标题以日期或「日报 / 周报 + 日期」开头，可带前导图标。取有效日期标题中最浅的标题层级为报告层级，较深标题留在正文，同层或更浅的非日期标题结束当前篇。含「周报」的日期标题归为周报，其他归为日报；范围采用首个日期排序。同日多篇保留，以标题和出现次序生成 ID，正文修改和新增其他日期不影响 ID。源文档如调整标题或同标题重复段的顺序，原深链可能变化。

正文保留 Markdown 标题、列表缩进；HTML 表格逐行转换为竖线分隔的单元格文字。页面按纯文本显示，不执行 HTML。没有日期标题的说明不单独生成报告。
